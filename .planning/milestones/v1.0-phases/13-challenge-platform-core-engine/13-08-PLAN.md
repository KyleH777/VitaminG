final class NotificationDelegate: NSObject, UNUserNotificationCenterDelegate {

    private let onDeepLink: (String, [AnyHashable: Any]) -> Void

    /// - Parameter onDeepLink: Called with `(deepLink, userInfo)` when the user taps a notification.
    ///   The full `userInfo` is forwarded so callers can extract additional payload values
    ///   (e.g. `userChallengeID` for challenge reminder taps — CR-01 / CHAL-12).
    init(onDeepLink: @escaping (String, [AnyHashable: Any]) -> Void) {
        self.onDeepLink = onDeepLink
        super.init()

    // MARK: - UNUserNotificationCenterDelegate

    /// Called when the user taps a notification (NOTIF-07, CHAL-12).
    /// T-03-09: Guard cast ensures only payloads carrying a String `deepLink` value
    /// trigger the callback; unknown or malformed values are silently ignored.
    /// The full userInfo is forwarded so the caller can extract additional keys
    /// (e.g. `userChallengeID` for the challenge check-in route).
    func userNotificationCenter(
        _ center: UNUserNotificationCenter,
        didReceive response: UNNotificationResponse,
        withCompletionHandler completionHandler: @escaping () -> Void
    ) {
        let userInfo = response.notification.request.content.userInfo
        if let deepLink = userInfo["deepLink"] as? String {
            onDeepLink(deepLink, userInfo)
        }
        completionHandler()
    }

    /// Shows notification banner and plays sound even when the app is in the foreground.
    func userNotificationCenter(
        _ center: UNUserNotificationCenter,
        willPresent notification: UNNotification,
        withCompletionHandler completionHandler: @escaping (UNNotificationPresentationOptions) -> Void
    ) {
        completionHandler([.banner, .sound])
    }
}

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| iOS notification system → app | The `userInfo` dictionary is delivered from the OS but originates from app-scheduled notifications (`NotificationScheduler.scheduleChallengeReminder`). Treat as semi-trusted: the structure is controlled by our own code path, but a malformed/tampered payload (e.g. via stale notifications after a downgrade) must not crash. |
| `userChallengeID` string → SwiftData fetch | The string is used downstream by `ContentView` to resolve a `UserChallenge` from `@Query`. The fetch lookup itself does not execute the string as code, but a non-UUID string must not match any record (silent no-op). |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-13-08-01 | Tampering | `NotificationDelegate.userNotificationCenter` reads arbitrary `userInfo` keys | mitigate | `if let deepLink = userInfo["deepLink"] as? String` cast guards against missing/non-string `deepLink`; closure not invoked when guard fails. Existing T-03-09 pattern preserved. |
| T-13-08-02 | Tampering | `VitaminGApp` closure casts `userInfo["userChallengeID"]` to String | mitigate | `let idString = userInfo["userChallengeID"] as? String` guard rejects non-string values silently — no crash, no mutation. Downstream `ContentView` already validates the UUID by `@Query`-matching; an invalid UUID resolves to no `UserChallenge` and the sheet simply does not present. |
| T-13-08-03 | Information Disclosure | userInfo could in theory carry extra keys | accept | Closure reads only the two known keys (`deepLink`, `userChallengeID`); unknown keys are ignored. No logging of userInfo to disk or console — no PII leakage path. |
| T-13-08-04 | Denial of Service | Malformed notification payload causes crash | mitigate | All casts use `as?` (optional); failed casts skip the branch silently. `completionHandler()` is always invoked unconditionally so the iOS notification machinery is not blocked. |
| T-13-08-05 | Elevation of Privilege | Tap routing bypasses authorization check | accept | Notification taps only set router state; they do NOT bypass authentication boundaries. ASVS L1: this app has no auth boundary — local-only data, CloudKit private DB scoped to user's iCloud account. |
</threat_model>
