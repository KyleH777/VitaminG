## Design System Source

No new tokens are introduced in Phase 13 — the challenge accent color system uses the
same `accentColorHex` convention already used by `GoalTier.color`.

## Spacing Scale

Declared values (multiples of 4 only):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4pt | Icon-to-label gap, tight inline spacing, StreakChainView dot gap |
| sm | 8pt | Card inner padding (vertical), row element gaps |
| md | 16pt | Default horizontal padding, card content padding |
| lg | 24pt | Section separation, NavigationStack scroll padding |
| xl | 32pt | Empty state icon margin, major layout section gap |
| 2xl | 48pt | Full-screen celebration badge top spacing |
| 3xl | 64pt | Not used in Phase 13 |

Exceptions:
- StreakChainView day-dot horizontal spacing: 4pt between circles (xs) — confirmed from D-09 pattern
- TouchTarget minimum: 44pt height for all interactive buttons (iOS HIG) — applies to check-in CTA, Join button, reminder time picker row
- Progress bar height: 8pt (2 × sm) — proportional to ProgressRingView lineWidth (3pt) pattern
- StreakChainView circle diameter: 20pt (from Claude's Discretion in CONTEXT.md — resolved here)

## Typography

All type uses `.fontDesign(.rounded)` on system fonts, consistent with existing views
(GoalDetailView, DailyWinsView, StatsView patterns).

Exactly 2 weights are used: `.regular` (400) and `.semibold` (600).
Exactly 4 sizes are declared: `.caption` (~12pt), `.body` (~17pt), `.title2` (~22pt), and the 48pt display counter.

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Display | `.title2` (~22pt Dynamic Type) | `.semibold` (600) | 1.2 | Challenge template title on discovery card, detail header, section headers ("Featured Challenges", "Browse by Category"), day counter label, milestone celebration message |
| Body | `.body` (~17pt Dynamic Type) | `.regular` (400) | 1.5 | Challenge description text, check-in field labels, reminder picker |
| Label / Caption | `.caption` (~12pt Dynamic Type) | `.regular` (400) | 1.4 | Community size ("1,240 people"), streak count labels, day-dot accessibility text |
| Day Counter | 48pt fixed | `.semibold` (600) | 1.2 | Prominent day counter for sobriety-type challenges |

Special cases:
- Day counter (sobriety-type challenge): `.system(size: 48, weight: .semibold, design: .rounded)` — matches StatsView global streak display pattern. Weight is `.semibold` (600), consistent with the 2-weight contract.
- Milestone badge SF Symbol: displayed at 64pt image scale (`.imageScale(.large)` + `.font(.system(size: 64))`)
- Quote/inspiration card (if shown in challenge detail): `VGTheme.serifItalic(17)` — matches GoalDetailView quote pattern

Note: All font sizes are Dynamic Type text styles, not hardcoded CGFloat values, except
the day counter (48pt) and milestone badge (64pt) which intentionally use fixed sizes
for display impact (same precedent as StatsView streak counter).

The former `.title3` role has been consolidated into the `.title2` Display role. All previously
`.title3`-referenced elements (section headers, day counter label) now use `.title2.weight(.semibold).fontDesign(.rounded)`.

## Color

Source: `VGTheme.swift` (established Phase 1, extended Phase 2).

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `VGTheme.sandLight` (#FAF5EE) | Screen background (`.background`), scroll view background |
| Secondary (30%) | `Color(.secondarySystemGroupedBackground)` | Challenge cards, check-in modal card surface, detail sections |
| Accent (10%) | Per-template `accentColorHex` (see below) | Reserved list — see "Accent reserved for" section |
| Destructive | `Color.red` (system red) | Abandon challenge confirmation action only |

### Accent Color System

Challenge templates carry their own `accentColorHex` — seeded values:
- 90-Day Summer Body: `#FF6B4A` (warm orange, close to `VGTheme.terraSoft`)
- Save $5,000: `#4A90E2` (calm finance blue — distinct from GoalTier.longTerm blue `#6699F2` to avoid confusion)
- Dry Summer: `#7A9E7E` (sage green, matches `VGTheme.sage`)

These are decoded from `ChallengeTemplate.accentColorHex` at runtime using:
```swift
Color(hex: accentColorHex ?? "#C4673A") // fall back to VGTheme.terra
```

**Accent reserved for:**
- StreakChainView filled day-dot fill color
- StreakChainView today circle stroke (2pt)
- Challenge card header/icon tint on discovery screen
- "Join Challenge" button background
- Progress bar fill toward goal value
- Active check-in CTA button background
- Milestone celebration badge tint and confetti primary color

**Accent NOT used for:**
- Navigation chrome (tab bar uses system default)
- Body text
- Background surfaces
- The "Abandon Challenge" destructive action (uses system red, not template accent)

### Adaptive Color Compliance

All surfaces must use semantic adaptive colors for Dark Mode (established in Phase 5/9):
- `Color(.systemBackground)` or `VGTheme.warmWhite` for primary surfaces
- `Color(.secondarySystemGroupedBackground)` for card fills
- `VGTheme.muted` for secondary/placeholder text (adaptive opacity sufficient)
- Never `Color.white` hardcoded (UI-05 violation — fixed in Phase 9)

## Component Inventory

New components introduced in Phase 13:

### StreakChainView
- Location: `Views/Components/StreakChainView.swift`
- 30 day circles in horizontal `ScrollView(.horizontal)`
- Circle diameter: 20pt; stroke width: 2pt (outlined/missed), 0pt stroke (filled/checked-in)
- Today's circle: template accent color stroke at 2pt (outlined if no check-in, filled if checked in)
- Missed day circle: `accentColor.opacity(0.25)` stroke, clear fill
- HStack spacing: 4pt (xs token)
- Horizontal padding: 16pt (md token) inside ScrollView
- Accessibility label: "Streak chain: N check-ins in the last 30 days"

### ChallengeCard (discovery screen)
- `.secondarySystemGroupedBackground` card fill
- 12pt corner radius (matches existing TierCardView corner radius)
- Horizontal padding 16pt, vertical padding 12pt
- Template icon (SF Symbol) at 32pt, template accent color tint
- Challenge title: `.title2.weight(.semibold).fontDesign(.rounded)`
- Description (1 line, truncated): `.body.fontDesign(.rounded)` with `.lineLimit(1)`
- Community size badge: `.caption.fontDesign(.rounded)`, `VGTheme.muted` foreground
- "Join" button: template accent fill, white label, `.body.weight(.semibold)`, 44pt minimum height

### ChallengeDiscoveryView layout

**Screen-level focal point:** The primary visual anchor when a user first lands on the Challenges tab is the Featured Challenges section — the first ChallengeCard's template icon and title draw the eye as the leading hero element.

Top-to-bottom structure:
1. `.navigationTitle("Challenges")` — `.title2.weight(.semibold)` (system nav title)
2. "Featured Challenges" section header — `.title2.weight(.semibold).fontDesign(.rounded)`
3. Featured ChallengeCard list (vertical LazyVStack, 12pt gap)
4. "Browse by Category" section header — `.title2.weight(.semibold).fontDesign(.rounded)`
5. Category row (horizontal scroll or grid)
6. "Build Your Own" CTA button — full width, secondary style, 44pt height

### ChallengeDetailView layout (top-to-bottom)
1. Large title header — challenge name in `.title2.weight(.semibold).fontDesign(.rounded)`
2. Category + duration badge row — `.caption` weight regular
3. Check-in CTA button — full width, template accent fill, "Log Today's Check-In" label
4. StreakChainView — below CTA, 8pt top margin
5. Progress section — progress bar (if goal_type = "target") OR day counter (if goal_type = "dateBound" / sobriety) — 16pt top margin
6. Reminder time picker row — 16pt top margin, inline disclosure pattern matching SettingsView rows
7. Description section — 24pt top margin

### ChallengeCheckInView (modal sheet)
- Presented as `.sheet` (not fullScreenCover) — preserves swipe-to-dismiss
- Boolean type: single toggle row + "Save Check-In" button
- Numeric type: `TextField` with numeric keyboard + unit label + "Save Check-In" button
- Multi-step type: two-step wizard with progress indicator (Step 1 of 2 / Step 2 of 2) at top
  - Step 1: boolean workout toggle
  - Step 2: numeric duration field (minutes)
  - "Next Step" / "Save Check-In" button label changes between steps
- All modal sheets: `.background(Color(.systemGroupedBackground))` surface

### MilestoneCelebrationView (fullScreenCover)
- Full black background with opacity 0.92 overlay
- Confetti: SwiftUI canvas particle system (`TimelineView` + `.drawingGroup`) — no third-party library
- Badge SF Symbol (per milestone config), rendered at 64pt, template accent color
- Milestone message: `.title2.weight(.semibold).fontDesign(.rounded)`, white foreground
- Challenge title attribution: `.body.fontDesign(.rounded)`, white at 0.8 opacity
- "Keep Going" dismiss button: template accent fill, 44pt height, 24pt horizontal padding
- Animation: `.spring(response: 0.5, dampingFraction: 0.7)` for badge scale-in from 0.3 to 1.0

### Milestone Badge SF Symbols (resolved from Claude's Discretion)
| Threshold | SF Symbol | Rationale |
|-----------|-----------|-----------|
| 7 days | `flame.fill` | "Streak is on fire" — warm, energetic |
| 30 days | `trophy.fill` | Milestone achievement marker |
| 60 days | `medal.fill` | Mid-challenge persistence |
| 90 days | `star.fill` | Full challenge completion (matches lifeGoal tier icon) |

### Progress Section Layout (resolved from Claude's Discretion)
The progress bar sits **above** the StreakChainView in the detail layout — goal value
progress is the primary metric; daily chain is the supporting context.

Revised order:
1. Check-in CTA button
2. Progress bar / day counter (8pt top margin)
3. StreakChainView (12pt top margin, below progress)

Rationale: Users arriving from the discovery screen want to see "how far I am toward
the goal" first, then "what my recent streak looks like" as secondary context.

## Interaction Contract

### Navigation Flow

```
Challenges Tab Root (ChallengeDiscoveryView)
  └─ Tap challenge card ──> NavigationStack push: ChallengeDetailView
       └─ Tap "Log Today's Check-In" ──> .sheet: ChallengeCheckInView
            └─ Submit ──> dismiss sheet ──> [if milestone] .fullScreenCover: MilestoneCelebrationView
  └─ Tap "Build Your Own" CTA ──> .sheet: "Custom challenges coming soon" placeholder
```

### "Already Checked In Today" State
- CTA button label changes to "Checked In Today" with `.checkmark.circle.fill` icon
- Button is disabled (`.disabled(true)`)
- Button background: `VGTheme.sage.opacity(0.6)` (muted green, not template accent)
- Accessibility: `.accessibilityLabel("Already checked in for today")`

### "Join Challenge" vs "Active" State on Discovery Card
- Pre-join: "Join Challenge" button with template accent fill
- Post-join (UserChallenge exists): "View Progress" button, system secondary style
- State determined by VM join status check — no per-type branching

### "Build Your Own" Placeholder Sheet
- Title: "Custom Challenges"
- Body: "Design your own challenge with custom goals, check-in types, and duration. Coming soon."
- Single dismiss button: "Got It"
- Background: `.systemGroupedBackground`

### Abandon Challenge
- Trigger: destructive button in challenge detail ("Abandon Challenge")
- Confirmation: `.confirmationDialog` with title "Abandon this challenge?" and message "Your progress will not be deleted, but your streak will end."
- Buttons: "Abandon" (`.destructive` role) + "Keep Going" (default, dismisses dialog)
- Uses system red (not template accent) per destructive color contract

### Tone Rules (from REQUIREMENTS.md UI-02)
- Warm and encouraging — never productivity-aggressive
- "Log Today's Check-In" not "Complete Task"
- "Checked In Today" not "Done / Completed"
- "Keep Going" not "Close" (milestone and abandon dialog)
- "Your Streak" not "Streak Count"
- "Next Step" not "Next" (multi-step wizard advance button — communicates progress in a sequence)
- Milestone messages from `MilestoneConfig.message` — seeded with human warmth ("One week strong!", "A whole month! Keep going.", "You did it! 90 days!")

## Accessibility Contract

| Requirement | Implementation |
|-------------|---------------|
| StreakChainView VoiceOver | `.accessibilityLabel("Streak chain: N check-ins in the last 30 days")` on the ScrollView |
| Day-dot individual accessibility | `.accessibilityHidden(true)` on each Circle — aggregate label sufficient |
| Join/View Progress button | `.accessibilityLabel("Join [challenge title]")` / `"View progress for [challenge title]"` |
| Check-in CTA disabled state | `.accessibilityLabel("Already checked in for today")` |
| Progress bar | `.accessibilityLabel("Progress: N% toward goal")` |
| Day counter | `.accessibilityLabel("N days alcohol-free")` (or appropriate unit) |
| Milestone celebration | `.accessibilityLabel("Milestone reached: [message]")` on badge |
| Confetti | `.accessibilityHidden(true)` — decorative only |
| Minimum touch targets | 44pt height on all buttons (Join, CTA, Save, Abandon, Dismiss) |
| Dynamic Type | All text uses Dynamic Type text styles except display counters (48pt, 64pt) |
| Reduce Motion | StreakChainView: no animation. Milestone: skip scale animation, show badge statically |
