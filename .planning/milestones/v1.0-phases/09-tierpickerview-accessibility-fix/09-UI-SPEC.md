## Spacing Scale

Native SwiftUI spacing — maps to 8-point multiples. Values used in TierCardView:

| Token | Value | Usage in TierCardView |
|-------|-------|-----------------------|
| xs | 4pt | — |
| sm | 8pt | VStack internal spacing (`spacing: 8`) |
| md | 16pt | — |
| grid-gap | 12pt | LazyVGrid column spacing (`spacing: 12`) |
| card-v | 14pt | Card vertical padding (`.padding(.vertical, 14)`) |
| card-h | 10pt | Card horizontal padding (`.padding(.horizontal, 10)`) |
| icon-frame | 34pt | SF Symbol icon frame height (`.frame(height: 34)`) |
| corner-radius | 12pt | RoundedRectangle corner radius |
| border-width | 2pt | Selected card stroke line width |

Exceptions:
- 12pt grid gap (non-standard) — pre-existing from Phase 2 implementation; acceptable for 2x2 grid density
- 14pt vertical padding — intentionally asymmetric to accommodate icon + text stack; not changed in fix
- 10pt horizontal padding — compact card layout for 2x2 grid cell; not changed in fix

Source: TierPickerView.swift (codebase read 2026-04-18)

## Typography

All text in TierCardView uses Dynamic Type text styles — no hardcoded `pt` sizes for labels.

| Role | Text Style | Weight | Design | Usage |
|------|-----------|--------|--------|-------|
| Card label | `.subheadline` | `.semibold` | `.rounded` | Tier displayName (e.g. "Immediate Win") |
| Card caption | `.caption` | regular | `.rounded` | Tier description (2-line max) |
| Icon glyph | `.system(size: 28)` | regular | system | SF Symbol decorative icon — D-09 exception |

**D-09 Exception — Icon Size:**
The tier icon uses `.font(.system(size: 28))` rather than a Dynamic Type text style. This is an approved exception documented in TierPickerView.swift: the 28pt fixed size is a layout-fixed decorative SF Symbol in a constrained 2x2 grid cell. The card's label and description text still scale with Dynamic Type. This exception does NOT constitute a UI-06 failure.

**Color on text:**
- displayName: `.foregroundStyle(.primary)` — adapts to Light/Dark mode
- description: `.foregroundStyle(.secondary)` — adapts to Light/Dark mode
- icon: `tier.color` — per-tier semantic color (orange, blue, purple, red — defined on GoalTier)

Source: TierPickerView.swift (codebase read 2026-04-18); CONTEXT.md D-09 exception note.

## Color

This phase's color contract applies specifically to TierCardView. The app uses iOS semantic colors throughout — no hex tokens.

| Role | iOS Semantic Color | Usage |
|------|--------------------|-------|
| Dominant (60%) | `.systemGroupedBackground` | Screen background (set by parent view) |
| Secondary (30%) | `Color(.secondarySystemGroupedBackground)` | Unselected card fill — adaptive Light/Dark |
| Accent — selected fill | `tier.color.opacity(0.12)` | Selected card tinted background |
| Accent — selected border | `tier.color` | Selected card stroke (2pt, full opacity) |
| Accent — icon | `tier.color` | Per-tier SF Symbol color |
| Destructive | Not applicable | No destructive actions in TierPickerView |

**Key fix — previously failing UI-05:**
- Before fix (failing): `Color.white` for unselected card fill → harsh white in Dark Mode
- After fix (passing): `Color(.secondarySystemGroupedBackground)` → dark adaptive background in Dark Mode

Accent reserved for:
- Selected card tinted fill (opacity 0.12 of tier color)
- Selected card border stroke
- Tier SF Symbol icon glyph

Source: CONTEXT.md canonical_refs; TierPickerView.swift (codebase read 2026-04-18).

## Verification Scope

This spec exists to define the design contract for the ALREADY-IMPLEMENTED fix. The executor for Phase 9 performs verification against these contracts — not new implementation.

### UI-05 Contract (Dark Mode)
- TierCardView unselected fill MUST use `Color(.secondarySystemGroupedBackground)` or equivalent adaptive semantic color
- `Color.white` is prohibited in TierCardView fill
- In Dark Mode system appearance: unselected cards render with dark adaptive surface, not white

### UI-06 Contract (Dynamic Type)
- TierCardView `displayName` label MUST use `.font(.subheadline.weight(.semibold))` or equivalent Dynamic Type text style
- TierCardView `description` label MUST use `.font(.caption)` or equivalent Dynamic Type text style
- Hardcoded `.system(size:)` is prohibited for label and caption text
- Exception: icon `.font(.system(size: 28))` is permitted per D-09 (decorative, layout-fixed)

### Human Verification Items (runtime — cannot be confirmed from code alone)
1. **Dark Mode visual:** Open AddGoalView in Dark Mode on simulator or device — unselected tier cards must show dark adaptive background, not white rectangles
2. **Dynamic Type scaling:** Set Text Size to "Accessibility Extra Extra Extra Large" in Settings — tier card label and caption text must visibly scale; icon may remain fixed at 28pt
