**Create `VitaminG/Navigation/AppRouter.swift`:**

```swift
import Observation

/// Centralized navigation state for the app.
/// Injected into the SwiftUI environment so any view can navigate without coupling.
@Observable
final class AppRouter {
    var path: [AppRoute] = []

    func navigate(to route: AppRoute) {
        path.append(route)
    }

    func pop() {
        guard !path.isEmpty else { return }
        path.removeLast()
    }

    func popToRoot() {
        path.removeAll()
    }
}
```

Per D-07: Uses `@Observable` macro, NOT `ObservableObject`/`@Published`. Per D-08: `path` is the navigation stack state that `NavigationStack` binds to.
