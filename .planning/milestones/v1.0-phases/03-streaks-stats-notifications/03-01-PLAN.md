    ```swift
    import Foundation

    struct StreakEngine {
        /// Computes current streak — consecutive days ending at today (or yesterday if today has no event yet) with at least one CompletionEvent.
        /// - Parameters:
        ///   - events: Array of CompletionEvent records (STATS-06: sole source of truth)
        ///   - tier: If provided, only count events matching this tier (STATS-01). If nil, count all tiers (STATS-02).
        ///   - calendar: Injectable calendar for testability (STATS-03: DST-safe)
        /// - Returns: Number of consecutive days
        static func currentStreak(
            from events: [CompletionEvent],
            tier: GoalTier? = nil,
            calendar: Calendar = .current
        ) -> Int
    ```

    Algorithm:
    1. Filter events by tier if provided; otherwise use all events
    2. Extract unique calendar days via `calendar.startOfDay(for:)` into a `Set<Date>` — compactMap over `completedAt`, skip nil (STATS-03)
    3. Let `today = calendar.startOfDay(for: Date())`
    4. Start candidate at `today`. If today is NOT in the set, move candidate to yesterday (the day isn't over yet — this handles test 11)
    5. Walk backward: while `days.contains(candidate)`, increment streak, move candidate back one day via `calendar.date(byAdding: .day, value: -1, to: candidate)`
    6. Return streak count

    Also implement:

    ```swift
    static func completionRate(

        tier: GoalTier? = nil
    ) -> Double
    ```
