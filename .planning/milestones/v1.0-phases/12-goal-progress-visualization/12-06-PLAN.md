  <name>Task 2: Human visual verification on iPhone 15 Simulator</name>
  <what-built>
Phase 12 Goal Progress Visualization end-to-end:
- Progress ring on every goal card (replaces the prior tier pip)
- Per-goal bar chart in GoalDetailView (Progress History card)
- Momentum score row with color dot (green/orange/secondary) in GoalDetailView
- Milestone celebration badge (star.fill / trophy.fill) on the goal card at 5/10/25/50 cumulative completions
- Reduced-motion path: static ring fill, static badge, no chart animation
  </what-built>
  <how-to-verify>
1. **Open Xcode** at `~/Desktop/AI/Vitamin G/VitaminG/VitaminG/VitaminG.xcodeproj`. Select the iPhone 15 Simulator and run the app.

2. **PROG-01 — Progress ring on cards**
   - Create a new goal in any tier (use the `+` toolbar button)
   - Observe the goal row: a 28pt circular ring sits at the trailing edge where the old tier pip used to be
   - Tap the completion toggle three times across three different days (or seed events via Xcode debug menu if available); the ring should fill proportionally — about 3/7 of a full circle for 3 events
   - Tap to fully complete the goal — the ring fills 100% in the green "completed" color
   - Re-activate the goal — ring returns to the proportional fill

3. **PROG-02 — Progress history in detail view**
   - Tap a goal to enter GoalDetailView
   - Scroll to the "Progress History" card (between the inspiration quote and Notes)
   - Verify "Total completions: N" row, "Last completed: <date>" row (or "Never" if no completions)
   - Verify a 30-bar chart in the goal's tier color, ~80pt tall
   - Verify the X-axis labels only the last 7 days with abbreviated day names (Mon, Tue, ...)
   - Verify the Y-axis is hidden (no numeric labels)

4. **PROG-03 — Milestone celebration badge**
   - Pick a goal and complete it 5 times (toggle ON 5 times — re-toggle off+on counts as a new event each on)
     - Note: each "toggle ON" creates a CompletionEvent. To force 5 events quickly: complete, uncomplete, complete, uncomplete, complete, uncomplete, complete, uncomplete, complete (5 ON cycles)
   - On the 5th completion, a star badge animates onto the card: scales up, holds ~1.5s, fades out
   - Repeat to reach 10, 25, 50 completions — verify badges fire
   - At 50 completions, the badge is `trophy.fill` instead of `star.fill`
   - Confirm the badge does NOT block taps or modal navigation — the rest of the UI remains responsive

5. **PROG-04 — Momentum row**
   - In GoalDetailView, locate the Momentum row (below the chart)
   - Verify the color dot is **gray** when the goal has 0 completions in the last 7 days
   - Verify the color dot is **orange** when 1–3 completions in the last 7 days
   - Verify the color dot is **green** when 4+ completions in the last 7 days (score ≥ 0.5)
   - Verify the trailing numeric value shows two decimals (e.g. "0.43")
   - Verify the subtitle reads "completions in the last 7 days"

6. **PROG-05 — No new model**
   - Run `grep -rE "@Model.*final class" VitaminG/VitaminG/VitaminG/Models/`
   - Confirm only existing models appear: Goal, CompletionEvent, UserProfile (in SchemaV2), DailyWin (in SchemaV3)
   - No new `@Model` declarations introduced by Phase 12

7. **Reduced motion check**
   - In Simulator: Settings → Accessibility → Motion → Reduce Motion → ON
   - Re-trigger a milestone (5/10/25/50): badge appears static (no scale animation), holds briefly, fades
   - Toggle a goal completion: ring snaps to the new fill instantly (no easeInOut)

8. **VoiceOver spot-check (optional)**
   - Enable VoiceOver in Simulator settings
   - Focus on a progress ring — VoiceOver reads "{N}% momentum this week" or "Goal complete"
   - Focus on the Momentum row — VoiceOver reads "Momentum score 0.43. Medium. Based on completions in the last 7 days."
   - Cross a milestone — VoiceOver announces "Milestone reached: 5 completions!"

**If any check fails, type a description of the issue. The plan executor will diagnose and fix before re-requesting approval.**

**If all checks pass, type `approved`.**
