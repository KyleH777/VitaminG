# Requirements: Vitamin G v3.0 Personal Intelligence + Apple Watch

**Defined:** 2026-05-28
**Core Value:** Every morning, the user is reminded of their goals — making progress feel inevitable, not accidental.
**Milestone goal:** Extend Vitamin G to the wrist and make it smarter — Apple Watch companion with complication and check-in, deep analytics with CSV export, AI-powered goal suggestions and personalized daily motivation via Claude, and notifications that adapt to streak and habits.

---

## v3.0 Requirements

### Apple Watch (WATCH)

- [x] **WATCH-02**: User sees their active goal title and a progress ring in a watchOS `accessoryRectangular` complication on their watch face; data stays current via WatchConnectivity snapshot delivery
- [x] **WATCH-03**: User taps the complication to open the Watch app and sees a single large Check In button; tapping it relays the check-in to the iPhone via `WCSession.transferUserInfo(_:)` and triggers the same check-in logic as the iOS app (streak update, widget reload, streak-at-risk notification cancellation)

### Analytics (ANLT)

- [ ] **ANLT-02**: User opens an Analytics view and sees a bar or line chart (Swift Charts) of their weekly and monthly goal completion rate across all active and completed goals
- [ ] **ANLT-03**: User taps any goal and sees a full all-time GitHub-style heatmap from the goal's creation date to today; heatmap renders without stutter for 1000+ days (LazyHStack)
- [ ] **ANLT-04**: User taps Export on the Analytics view and receives a CSV file (via `ShareLink`) containing every CompletionEvent — goal name, date, tier — shareable to Files, Mail, or any other app

### AI — Claude via Cloudflare Worker (AI)

- [ ] **AI-03**: A Cloudflare Worker proxy is deployed at a stable URL and forwards POST requests from the iOS app to the Anthropic Messages API; the Worker holds the Anthropic API key server-side (never in the iOS binary); the Worker returns Claude's response to the app
- [ ] **AI-01**: User opens the Explore tab and sees a "Goals suggested for you" card with 3 Claude-generated goal suggestions based on their existing goal titles and categories; tapping one adds it to their goal list with a single tap; suggestions refresh at most once per day (cached in UserDefaults)
- [ ] **AI-02**: User sees a personalized daily motivation message on the Home tab above the My Goals list; the message is generated by Claude using the user's current streak count and active goal titles; it is cached per calendar day (one API call maximum per day) and falls back to the existing `VGQuoteBank` copy if the API is unavailable

### Smart Notifications (NOTIF)

- [ ] **NOTIF-01**: Daily morning notification copy tone adapts to the user's current streak — celebratory phrasing for streaks ≥ 7 days, encouraging phrasing for streaks < 3 days or a broken streak, neutral for everything in between; tone selection is local (no network call)
- [ ] **NOTIF-02**: Daily morning notification body references the user's actual active goal titles (up to 2) rather than generic placeholder copy
- [ ] **NOTIF-03**: App analyses the user's last 14 days of check-in timestamps; if the modal check-in hour differs from the current nudge time by 2 or more hours, a non-intrusive banner appears in Settings suggesting the user shift their nudge time — tapping it applies the change
- [ ] **NOTIF-04**: Each morning when the daily nudge fires, the app schedules a second `UNCalendarNotificationTrigger` (streak-at-risk alert) for 7 PM that day; this alert is cancelled automatically the moment the user checks in via the iOS app, a widget, or the Apple Watch

## Out of Scope

| Feature | Reason |
|---------|--------|
| Android / cross-platform | iOS-native only |
| Web dashboard | Native iOS is the experience |
| Embedded Anthropic API key | ToS violation + security risk — Cloudflare Worker proxy is mandatory |
| Watch-native SwiftData store | CloudKit iOS-Watch sync is unreliable; WatchConnectivity is the only supported bridge |
| Push notifications via APNs server | Local notifications only — no backend notification infrastructure |
| AI features without fallback | All AI screens must degrade gracefully when proxy is unreachable |
