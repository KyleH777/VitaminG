## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User camera / photo library → PostComposeSheet | Raw image data from device camera/library crosses into compose flow before CloudKit write |
| User typed reply → CommunityReplySheetView → CloudKit | Reply text string crosses from view to public CloudKit DB |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-21-04-01 | Tampering | Reply text → CloudKit public DB | mitigate | ProfanityFilter.containsProfanity() in submit() before any write; InputSanitizer.sanitizeForPublic() in CommunityService.writeReply |
| T-21-04-02 | Information Disclosure | Camera roll access via UIImagePickerController | accept | AVFoundation camera access requires prior permission; ProfileView.swift already uses this pattern and requires user to have granted camera permission — same gate applies |
| T-21-04-03 | Tampering | Photo upload — malformed JPEG bypass compressToJPEG | accept | compressToJPEG uses UIImage(data:) as the entry point — malformed data returns nil (no write); max 500KB enforced by existing compressToJPEG step-down loop |
| T-21-04-04 | Denial of Service | 300-char limit bypass | mitigate | Hard cap enforced in .onChange(of: text) — text.prefix(300) applied on every keystroke |
| T-21-04-SC | Tampering | npm/pip/cargo installs | accept | No package manager installs — all Apple-native |
</threat_model>
