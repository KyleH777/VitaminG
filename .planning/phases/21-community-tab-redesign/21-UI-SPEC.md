## Spacing Scale

Declared values (SwiftUI points, 1pt = 1px on non-Retina baseline; all multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4pt | Icon-to-label gap, reaction pill internal padding |
| sm | 8pt | AvatarView-to-text gap, inline chip spacing, card internal row spacing |
| md | 16pt | Default horizontal section padding, card horizontal padding |
| lg | 24pt | Tab page-header horizontal padding, section-to-section vertical break |
| xl | 32pt | Major section separation in the hub scroll |
| 2xl | 48pt | Reserved — not used in Phase 21 |
| 3xl | 64pt | Reserved — not used in Phase 21 |

**Exceptions:**
- Touch targets for all tappable cards (Glimpse cards, Active Today avatars, applause button): minimum 44pt height — per Apple HIG accessibility requirement.
- `CommunityGoalCard` (COMM-01) top padding from navigation bar: 20pt (matches existing `CommunityTabView` header pattern — verified line 24).
- Glimpse card internal padding: 12pt vertical / 16pt horizontal — matches `CommunityPostCard.swift` lines 109–110 pattern.
- `ActiveTodaySection` avatar-to-avatar spacing: 12pt — matches `CommunityPostCard.swift` lines 109–110 pattern.
- `GlowingSpotlightSection` allcaps label tracking: 0.5pt — visual detail only, not a layout spacing value; 12pt used as vertical margin between allcaps label and username — matches `CommunityPostCard.swift` lines 109–110 pattern.
- `GlowingSpotlightSection` hero card: 24pt internal padding on all sides to convey elevated status.

**Source:** Verified from `CommunityPostCard.swift` lines 109–110, `CommunityTabView.swift` lines 24–26.

## Typography

Two type families used. Exact values derived from existing codebase usage (VGTheme.swift lines 142–156, grep across Views/).

Maximum 4 distinct sizes. Caption text is visually differentiated from Label/Secondary using `VGTheme.textMuted` color only — no separate size tier.

| Role | Size | Family / Weight | Line Height | Usage |
|------|------|-----------------|-------------|-------|
| Tab Heading | 28pt | Cormorant Garamond Regular (`VGTheme.serif(28)`) | 1.2 | "Community" tab title at top of scroll — matches existing pattern (CommunityTabView line 22) |
| Section Heading | 20pt | SF Pro Rounded Semibold (`.system(size: 20, weight: .semibold).fontDesign(.rounded)`) | 1.2 | Section labels: "Today's Glimpses", "Active Today", "Glowing This Week", community feed header |
| Body | 17pt | SF Pro Rounded Regular (`.system(size: 17).fontDesign(.rounded)`) | 1.5 | Post body text, reply text, goal title on Glimpse cards, Glowing spotlight bio |
| Label / Secondary | 14pt | SF Pro Rounded Regular (`.system(size: 14).fontDesign(.rounded)`) | 1.4 | Username labels on Glimpse cards, Active Today names, reaction counts, progress percentage, relative timestamps ("3 min ago"), applause float username label, "once per day" limit label, "Glowing This Week" allcaps label, progress % labels, reply character counter — use `VGTheme.textMuted` color to distinguish secondary/caption roles from primary label roles |

**Two weights max:**
- Regular (400): body text, labels, captions
- Semibold (600): section headings, CTA buttons, author names in post cards

**Source:** Derived from `CommunityPostCard.swift` lines 38–44, `CommunityFeedView.swift` lines 44–55, `CommunityGoalsLandingView.swift` lines 84–122, `VGTheme.swift` typography helpers.

## Color

All tokens are from `VGTheme.swift`. Values given as light-mode hex; dark-mode adaptive variants are defined in VGTheme.

| Role | VGTheme Token | Light Hex | Dark Hex | Usage |
|------|--------------|-----------|----------|-------|
| Dominant (60%) | `VGTheme.background` | #FAF5EE (sandLight) | #16110C (inkDeep) | Tab background, scroll area surface |
| Secondary (30%) | `VGTheme.surface` / `VGTheme.backgroundSecondary` | #FDFAF6 (warmWhite) | frosted warm tint | Cards (Glimpse cards, Active Today row, post cards), compose sheet |
| Accent — Terra (10%) | `VGTheme.accentTerra` | #C4673A | #FF8A5C | Primary CTA buttons ("Post Update", "Compose"), active reaction pills, progress circle fill on Glimpse cards |
| Accent — Gold | `VGTheme.accentGold` | #C4A459 | #E8D070 | Applause float emoji + username text, "Glowing This Week" spotlight card border/glow ring |
| Separator | `VGTheme.separator` | #E8D9C4 (sandMid) | hairline warm | Card borders, section dividers |
| Text Primary | `VGTheme.textPrimary` | #3D2F1E (clay) | #F2E8D9 (sand) | All primary text (headings, body, usernames) |
| Text Secondary | `VGTheme.textSecondary` | clay @ 75% | sand @ 62% | Goal titles in Glimpse cards, post preview text |
| Text Muted | `VGTheme.textMuted` | #9A8A78 | sand @ 42% | Timestamps, progress % secondary labels, "once per day" notice, reply count, allcaps section labels in spotlight card — used to distinguish caption-role Label/Secondary text from primary Label/Secondary text |
| Destructive | `.red` (system) | system red | system red | Report post confirmation button only (uses SwiftUI `.role: .destructive` on `.confirmationDialog`) |

**Accent reserved for:**
- Terra accent: primary compose/post CTA button fill, active state of reaction pills (❤️, 🔥, 👍 when selected), Glimpse card progress circle ring
- Gold accent: floating 👏 emoji animation text color, Glowing This Week card highlight ring/border, "Glowing This Week" label text

**60/30/10 note:** The Community tab is a warm sand/warmWhite surface (dominant). Cards sit on `surface`/warmWhite (secondary). Terra and Gold accents are reserved for interactive states and celebratory highlights only — not used for general UI chrome.

**Source:** VGTheme.swift (verified), CONTEXT.md §specifics — "warm clay/terra palette", ApplauseButtonView pattern in RESEARCH.md line 337 references `VGTheme.accentGold`.

## Interaction States

### Applause Button (SOC-01 / D-05)

| State | Visual |
|-------|--------|
| Available (canApplaud: true) | 👏 emoji at full opacity (1.0), accentGold color, tappable |
| Disabled (already applauded today) | 👏 emoji at 0.4 opacity, no active color, `.disabled(true)` — accessibilityLabel: "Already applauded today" |
| Triggered (animation) | 👏 + giverUsername float upward 80pt over 1.0s, fade to opacity 0 using `.easeOut(duration: 1.0)` — accentGold color |

### Reaction Pills (COMM-06, existing CommunityPostCard)

| State | Visual |
|-------|--------|
| Inactive | Outline capsule, muted text, emoji + count |
| Active | Filled capsule with `accentTerra` background, white text |

### Glimpse Carousel (COMM-02)

| State | Visual |
|-------|--------|
| Auto-advancing | Page dots visible, smooth `.easeInOut(duration: 0.4)` page transition every 5 seconds |
| Manual swipe active | Auto-advance paused while `isDragging = true`; resumes on drag end |
| Empty (no glimpses today) | Empty state card (see Copywriting) — no carousel rendered |

### Post Compose Button

| State | Visual |
|-------|--------|
| Default | Floating compose button (circle, accentTerra fill, SF Symbol `square.and.pencil`) — bottom trailing of feed section |
| Photo attached | Inline thumbnail preview at 80x80pt with rounded corners (8pt radius) in compose sheet |

## Section Layout Order

The rebuilt `CommunityTabView` scroll renders sections in this exact order, top to bottom:

1. Tab heading "Community" — 28pt serif, 20pt top, 24pt horizontal, 12pt bottom
2. `CommunityGoalCard` (COMM-01) — taps to `CommunityGoalsLandingView`
3. Section label "Today's Glimpses" (20pt semibold rounded) + `GlimpsesCarouselSection` (COMM-02/03)
4. Section label "Active Today" (20pt semibold rounded) + `ActiveTodaySection` (COMM-04)
5. `GlowingSpotlightSection` hero card — no section label; card is self-labeled (COMM-05/SOC-01)
6. Section label "Community Feed" (20pt semibold rounded) + compose button + `GlobalFeedSection` (COMM-06/07)

Section label top padding: 24pt. Section label bottom padding: 8pt.

## Accessibility

| Component | Requirement |
|-----------|------------|
| AvatarView | Existing `accessibilityLabel` on `AvatarView` is already set — do not override |
| Applause button (available) | `accessibilityLabel("Applaud \(recipientUsername)")` |
| Applause button (disabled) | `accessibilityLabel("Already applauded today")` |
| Glimpse carousel | `accessibilityLabel("Today's Glimpses. \(glimpses.count) cards.")` on the `TabView`. Individual cards: `accessibilityLabel("\(username)'s goal: \(goalTitle), \(progressPercent) percent complete")` |
| Reaction pills | Existing `ReactionPill` component already sets accessibilityLabel — do not re-specify |
| Active Today avatar | `accessibilityLabel("\(username), active today. Tap to view profile.")` |
| Progress circles | `accessibilityValue("\(progressPercent) percent")` |
| Touch targets | All interactive elements: minimum 44x44pt — use `.frame(minWidth:44, minHeight:44)` or `.contentShape(Rectangle())` as needed |

## Animation Contracts

| Animation | Spec |
|-----------|------|
| Carousel auto-advance | `.easeInOut(duration: 0.4)` on `currentIndex` change (matches existing pattern) |
| Applause float | `.easeOut(duration: 1.0)` on `floatOffset` (–80pt) and `floatOpacity` (0.0); `showFloat = false` after 1.1s via `DispatchQueue.main.asyncAfter` |
| Reaction pill tap | `.spring(response: 0.3, dampingFraction: 0.6)` scale pulse — matches existing `ReactionPill` component behavior |
| Photo thumbnail appear in compose | `.transition(.opacity)` — no elaborate animation |
| Feed load / skeleton | No skeleton. Show `ProgressView()` centered while `isLoading = true`. Disappears on data arrival |
