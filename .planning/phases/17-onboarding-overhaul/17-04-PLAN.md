| Boundary | Description |
|----------|-------------|
| PHPickerViewController → app | Photo data from user's photo library; must be resized/compressed before any storage or transmission |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-17-04-01 | Information Disclosure | Profile photo stored in OnboardingViewModel.profilePhotoData | mitigate | Compressed to ≤512px JPEG 0.75 via resizeAndCompress — reduces resolution and file size before any persistence; no full-resolution storage in Phase 17 |
