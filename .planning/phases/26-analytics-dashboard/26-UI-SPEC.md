## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|

| sm | 8px | Inline element spacing (HStack spacing), button label gap |

| xl | 32px | Major section breaks inside ScrollView |
| 2xl | 48px | Not used in this phase |
| 3xl | 64px | Not used in this phase |

### Inherited Non-Standard Values

The following values are **not** new design tokens and must not be generalised beyond their specific contexts:

| Value | Context | Reason for Exception |
|-------|---------|----------------------|
| 3 pt | `LazyHStack` column spacing in `AllTimeHeatmapView` | Pixel-exact copy of the existing `HeatmapView.swift` grid spacing. Changing this value would break visual consistency with the 90-day heatmap that appears on the same Stats screen. |
| 3 pt | Heatmap cell gap (`VStack(spacing: 3)` inside each week column) | Same source — verbatim from `HeatmapView.swift` cell/gap dimensions. |

These two 3 pt values are inherited for visual consistency with the existing heatmap component. They are not a new spacing token. The planner must not introduce any additional 3 pt spacings beyond these two carried-over values.

Additional non-standard exceptions:
- `AnalyticsView` ScrollView VStack spacing: 20 pt (matches `StatsView` pattern — source: StatsView.swift line 22).
- Card corner radius: 16 pt for list rows, 20 pt for full-width gradient cards (matches StatsView globalStreakCard).
- Chart height: 180 pt (taller than GoalDetailView's 80 pt; analytics chart warrants more vertical space).
- Touch targets: minimum 44×44 pt for all tappable goal list rows and export buttons.

**Source:** StatsView.swift measured values; HeatmapView.swift cell/spacing dimensions; CONTEXT.md D-01/D-02.

## Typography

All text uses the system font with `.fontDesign(.rounded)` unless noted as serif. This matches the established pattern in StatsView and GoalDetailView.

> **Navigation title size is system-controlled.** SwiftUI's `.navigationTitle("Analytics")` with `.navigationBarTitleDisplayMode(.large)` renders the large navigation title at approximately 34 pt bold. This size is not a manually declared design token — it is set entirely by the OS and cannot be overridden without using custom navigation bar appearance APIs. It is therefore excluded from the app's design scale below.

| Role | SwiftUI Modifier | Approx Size | Weight | Line Height |
|------|-----------------|-------------|--------|-------------|
| Display Number (streak count) | `.font(.system(size: 28, weight: .bold, design: .rounded))` | 28 pt | Bold (700) | 1.0 |
| Section Heading | `.font(.title3.weight(.semibold)).fontDesign(.rounded)` | 20 pt | Semibold (600) | 1.2 |
| Body / Goal Row Label | `.font(.body).fontDesign(.rounded)` | 17 pt | Regular (400) | 1.5 |
| Caption / Axis Label | `.font(.caption).fontDesign(.rounded)` | 12 pt | Regular (400) | 1.4 |

Exactly 4 size roles declared. 2 weights used: Regular (400) and Bold/Semibold (600–700).

Chart axis labels (X-axis bucket labels, Y-axis percent ticks): `.font(.caption)` via Swift Charts `AxisValueLabel` — 12 pt, regular weight.

**Source:** StatsView.swift font audit; GoalDetailView.swift line 449 pattern; RESEARCH.md Standard Stack.

## Layout Specification

**Primary focal point:** Completion Rate card (gradient header + BarMark chart) — positioned first in scroll order; gradient header distinguishes it from all other sections.

### AnalyticsView Layout

```
NavigationTitle: "Analytics" (.large)
ScrollView(.vertical)
  VStack(spacing: 20)
    ├── Completion Rate Card          [gradient header, 180pt chart, segmented control]
    │     ├── Section title: "Completion Rate"    (.title3.semibold.rounded)
    │     ├── Picker: Weekly | Monthly             (.segmented style)
    │     └── Chart (BarMark, height: 180pt)       (VGTheme.accentTerra fill)
    │
    ├── Goal List Section             [section title + ForEach goal rows]
    │     ├── Section title: "All Goals"           (.title3.semibold.rounded)
    │     └── ForEach(goals, active+completed)
    │           └── NavigationLink → GoalAllTimeHeatmapView
    │                 HStack:
    │                   [goal name .body.rounded] [Spacer] [chevron.right .secondary]
    │
    └── Export All Button             [ShareLink]
          Label("Export All Data", systemImage: "square.and.arrow.up")
          .font(.body.weight(.semibold)).fontDesign(.rounded)
  .padding(.horizontal, 16)
  .padding(.vertical, 20)
.background(Color(UIColor.systemGroupedBackground))
```

### GoalAllTimeHeatmapView Layout

```
NavigationTitle: {goal.title} (.inline)
ScrollView(.vertical)
  VStack(alignment: .leading, spacing: 16)
    ├── Date range label              (.caption.rounded, VGTheme.textMuted)
    │     "Since [goal.creationDate.formatted()] · [N] days"
    ├── AllTimeHeatmapView            (LazyHStack, horizontal scroll, scroll-to-end on appear)
    └── Export This Goal Button       (ShareLink, per-goal CSV)
          Label("Export Goal Data", systemImage: "square.and.arrow.up")
  .padding(16)
.background(Color(UIColor.systemGroupedBackground))
```

### AllTimeHeatmapView Internal Structure

```
ScrollViewReader { proxy in
  ScrollView(.horizontal, showsIndicators: false)
    LazyHStack(alignment: .top, spacing: 3)
      ForEach(weeks) { week in
        VStack(spacing: 3)         ← 7 day cells per column
          ForEach(days in week) { day in
            ZStack
              RoundedRectangle(cornerRadius: 2, width: 12, height: 12)
                .fill(cellColor(for: data[day] ?? 0))
              if data[day] == -1
                Image(systemName: "snowflake")  ← 7pt, .blue
    .padding(.horizontal, 8)
  .onAppear { proxy.scrollTo(weeks.count - 1, anchor: .trailing) }
}
```

## Interaction States

### Completion Rate Chart
| State | Behavior |
|-------|----------|
| Default | Weekly granularity shown on appear |
| Segmented control tap | Picker binding updates granularity; view body re-selects pre-computed bucket array (no refetch) |
| No data (zero events) | Chart renders with empty Y-axis; empty state message below chart: "Check in on goals to see your trends." |
| Loading | Not applicable — synchronous SwiftData `@Query` + `AnalyticsViewModel.refresh()` |

### Goal List
| State | Behavior |
|-------|----------|
| No goals | Empty state: full-width card with SF Symbol `chart.bar.doc.horizontal` + "No goals yet. Start tracking to see your history." |
| Active goals | Shown with goal title; no completion badge needed |
| Completed goals | Same row style; append "(completed)" as secondary caption below title using `.font(.caption).foregroundStyle(VGTheme.textMuted)` |

### AllTimeHeatmapView
| State | Behavior |
|-------|----------|
| On appear | `ScrollViewReader` scrolls immediately to last column (most recent week), no animation — `proxy.scrollTo(weeks.count - 1, anchor: .trailing)` without `withAnimation` |
| Goal with nil creationDate | ViewModel falls back: use earliest `completedAt` among goal's events, else 90 days ago |
| Current partial week | Week column renders only days up to today; future days show `Color(.systemFill)` (count 0) |
| Freeze day | Blue tint cell + snowflake SF Symbol (7pt) — verbatim from `HeatmapView` |

### Export
| State | Behavior |
|-------|----------|
| Default | `ShareLink` button always active — no loading state; CSV built synchronously in O(N) |
| Goal with no events | CSV contains header row only: `goal_name,date,tier,is_frozen` |
| Large history | No truncation; ShareLink accepts in-memory String; no disk write |

## CSV Export Contract

| Column | Source | Format |
|--------|--------|--------|
| `goal_name` | `event.goal?.title ?? "Unknown"` | RFC 4180 escaped (wrapped in double-quotes; embedded quotes doubled) |
| `date` | `event.completedAt` | ISO 8601 `YYYY-MM-DD` via `ISO8601DateFormatter` with `.withFullDate` |
| `tier` | `event.tierRawValue` | Raw string as stored: `"Immediate"`, `"Short-Term"`, `"Long-Term"`, `"Life Goal"` |
| `is_frozen` | Derived: check if event date is in `StreakFreezeService.frozenDates` set | `"true"` / `"false"` |

Sort order: date ascending (`completedAt` ascending, `distantPast` for nil).

Global export: all `CompletionEvent` records across all goals.

Per-goal export: `CompletionEvent` records where `event.goal?.id == goal.id`.

**Source:** CONTEXT.md D-10/D-11; RESEARCH.md CSV Export Pattern; RESEARCH.md Code Examples (tierRawValue verified values).

## Component Style Rules

1. **No new color tokens.** Use only existing `VGTheme` tokens. Do not introduce color names not in `VGTheme.swift`.
2. **No new font families.** System rounded (`.fontDesign(.rounded)`) for all UI text in this view. `VGTheme.serif` is not used in analytics — data density requires readable body font, not display serif.
3. **Card container style.** Goal list rows use `RoundedRectangle(cornerRadius: 16).fill(Color(UIColor.secondarySystemGroupedBackground))` — matches `StatsView.tierStreakGrid` card style.
4. **Segmented control tint.** Default system blue acceptable; do not force tint to `accentTerra` (segmented control tint override is not established in any existing view).
5. **NavigationLink chevron.** Use `Image(systemName: "chevron.right").foregroundStyle(.secondary)` at trailing — matches StatsView navigation row pattern.
6. **ShareLink icon.** Use `systemImage: "square.and.arrow.up"` — matches ProfileView ShareLink pattern.
