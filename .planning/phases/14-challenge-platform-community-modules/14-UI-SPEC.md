# Phase 14 — UI Design Contract
## Challenge Platform: Community & Modules

> Visual and interaction contract for the community feed, reactions, profanity
> filter feedback, all five optional modules (Spending Freeze, Craving Tools,
> Transformation Photos, Nutrition Log, Buddy Accountability), the Custom
> Challenge builder, and the full notification suite.
> Generated by gsd-ui-researcher. Verified by gsd-ui-checker.

## Spacing Scale

Identical to Phase 13 — no new values.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4pt | Reaction button gap, icon-to-label gap, dot spacing |
| sm | 8pt | Card inner padding (vertical), row element gaps, reaction pill padding |
| md | 16pt | Default horizontal padding, community feed card padding |
| lg | 24pt | Section separation, builder form section gap |
| xl | 32pt | Empty state icon top margin |
| 2xl | 48pt | Full-screen celebration spacing (inherited from Phase 13) |
| 3xl | 64pt | Not used in Phase 14 |

Exceptions:
- Reaction pill height: 32pt (sm × 4) — touch-friendly but compact to fit two pills side-by-side
- Community post photo thumbnail: 80pt × 80pt (5 × md)
- Box breathing circle minimum size: 200pt diameter (fills ~60% of screen width on SE)
- Transformation photo thumbnail grid: 80pt × 80pt cells, 8pt gap (sm)
- Touch target minimum: 44pt height on all interactive buttons (iOS HIG) — applies to post CTA, reaction pills, builder "Create" button, module toggles

## Typography

All type uses `.fontDesign(.rounded)` on system fonts. Inherits the 2-weight, 4-size
contract from Phase 13 without addition.

Exactly 2 weights: `.regular` (400) and `.semibold` (600).
Exactly 4 sizes: `.caption` (~12pt), `.body` (~17pt), `.title2` (~22pt), and the 48pt
display counter (box breathing countdown, inherited from Phase 13 day counter pattern).

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Display | `.title2` (~22pt Dynamic Type) | `.semibold` (600) | 1.2 | Community feed section header, builder section headers, module sheet titles, box breathing phase label |
| Body | `.body` (~17pt Dynamic Type) | `.regular` (400) | 1.5 | Post text, form field labels and values, motivational prompt text, meal note field, buddy name label |
| Label / Caption | `.caption` (~12pt Dynamic Type) | `.regular` (400) | 1.4 | Reaction counts, post timestamp, photo date label, "N of N" step indicator in builder |
| Breathing Counter | 48pt fixed | `.semibold` (600) | 1.2 | Box breathing countdown digit — same precedent as sobriety day counter in Phase 13 |

Special cases:
- Motivational distraction prompt body (Craving Tools): `VGTheme.serifItalic(17)` — quote-style presentation, matches GoalDetailView associatedInspiration pattern
- Profanity filter rejection inline message: `.caption.weight(.regular)` in `Color.red` (system) — smallest footprint that is still legible

Note: All sizes use Dynamic Type text styles except the breathing counter (48pt fixed)
which intentionally uses a fixed size for display impact.

## Color

Source: `VGTheme.swift`. No new tokens added in Phase 14.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `VGTheme.sandLight` (#FAF5EE) | Screen background for community feed, module sheets, builder form |
| Secondary (30%) | `Color(.secondarySystemGroupedBackground)` | Post cards, module option rows, builder section cards |
| Accent (10%) | Per-template `accentColorHex` (runtime) | Reserved list — see "Accent reserved for" section |
| Destructive | `Color.red` (system red) | Delete post confirmation action only |

### Phase 14 Accent Usage

The per-template accent color (resolved via `Color(hex: accentColorHex ?? "#C4673A")`)
is the sole accent source. For the Custom Challenge builder, the user-selected accent
color preview uses the same resolution.

**Accent reserved for:**
- "Post to Community" button background
- Reaction pill border when the current user has reacted (👍 or ❤️ highlighted state)
- Spending Freeze active badge background tint
- Box breathing circle fill (animates through 4 phases)
- "Ping Buddy" button background
- Custom Challenge builder "Create Challenge" primary CTA background
- Streak-at-risk notification badge tint (in-app banner only)

**Accent NOT used for:**
- Community post body text
- Report button (uses `VGTheme.muted` foreground — intentionally de-emphasized)
- Profanity rejection message (uses `Color.red` system)
- Background surfaces
- Navigation chrome

### Adaptive Color Compliance

Same rules as Phase 13 — no `Color.white` hardcodes:
- `VGTheme.sandLight` / `Color(.systemBackground)` for primary surfaces
- `Color(.secondarySystemGroupedBackground)` for cards and rows
- `VGTheme.muted` for secondary/placeholder text
- `VGTheme.clay` for primary text (dark, adaptive-safe)

## Interaction Contract

### Navigation Flow (Phase 14 additions)

```
Challenges Tab Root (ChallengeDiscoveryView)
  └─ Tap "Build Your Own" CTA ──> .sheet: CustomChallengeBuilderView (replaces coming-soon)
       └─ Fill Step 1 → "Next" ──> Step 2
            └─ Fill Step 2 → "Create Challenge" ──> dismiss sheet ──> new template in discovery

ChallengeDetailView (existing, Phase 13)
  └─ "Community" section link ──> NavigationStack push: CommunityFeedView
       └─ "Share Your Progress" ──> .sheet: PostComposeSheet
            └─ Submit post ──> dismiss sheet ──> post appears in feed
  └─ "Spending Freeze" section (if module enabled) ──> inline toggle (no navigation)
  └─ "Nutrition Log" section (if module enabled) ──> inline text field (no navigation)
  └─ "Craving Tools" button (if module enabled) ──> .sheet: CravingToolsModuleView
  └─ "Transformation Photos" row (if module enabled) ──> NavigationStack push: TransformationPhotosModuleView
  └─ "Buddy Accountability" button (if module enabled) ──> .sheet: BuddyAccountabilityModuleView
```

### Module Attachment Pattern

Modules are enabled per-challenge via the template config (array of module identifiers).
In ChallengeDetailView, a "Tools & Modules" section appears below the StreakChainView
only when at least one module is attached. Each module renders its own entry row:

```
Tools & Modules
  ├─ Spending Freeze ──> inline section expands below
  ├─ Craving Tools ──> .sheet: CravingToolsModuleView
  ├─ Transformation Photos ──> push: TransformationPhotosModuleView
  ├─ Nutrition Log ──> inline section expands below
  └─ Buddy Accountability ──> .sheet: BuddyAccountabilityModuleView
```

Module rows: `Label("Spending Freeze", systemImage: "snowflake")` pattern, 44pt height,
chevron disclosure (`chevron.right`, 12pt, `VGTheme.muted`) for sheet/push; no chevron for
inline expansion. Horizontal rule separator (1pt, `VGTheme.sandMid`) between rows.

### Community Post Reaction Interaction

- Tap 👍: immediate optimistic toggle of `isThumbsUp` state on the post card
- Tap ❤️: immediate optimistic toggle of `isHeart` state on the post card
- Only one reaction type per user per post — tapping a second reaction type removes the first
- CloudKit write occurs in background; on failure, revert to pre-tap state + show `.alert("Couldn't save your reaction. Please try again.")`
- Reaction counts show integers only (no K-abbreviation in Phase 14 — counts expected small)

### Report Post Interaction

- `flag.fill` SF Symbol button, top-right of every post card, `VGTheme.muted` tint
- Tap: `.confirmationDialog` with title "Report this post?" and message "This will send a report. The post will be hidden from your feed after 3 reports from different users."
- Buttons: "Report" (`.destructive` role) + "Cancel" (default)
- After confirming: post is hidden locally immediately (`.opacity(0)` then removed from list) — no confirmation success alert (silent removal is intentional UX)
- Report count is stored in CloudKit public database and never shown to any user

### Profanity Filter Rejection Flow

- Triggers on "Post" button tap in PostComposeSheet before any CloudKit write
- On-device word list check (synchronous) — never silently drops content
- Rejection state: TextEditor border becomes `Color.red` (1pt stroke), inline `.caption` error appears below editor
- "Post" button becomes disabled
- Error message: "Your post contains content that isn't allowed. Please edit and try again."
- User edits text → error clears on next character typed → "Post" re-enables when text is clean and non-empty

### Box Breathing Animation States

Four phases, each 4 seconds, cycling until user taps "Done":
1. Inhale: circle fills from 0% to 100% (accent color), label "Inhale", countdown 4→1
2. Hold: circle remains full, label "Hold", countdown 4→1
3. Exhale: circle drains from 100% to 0%, label "Exhale", countdown 4→1
4. Hold: circle remains empty, label "Hold", countdown 4→1

Reduce Motion: disable the fill/drain animation — show phase label + countdown only, static circle outline. Breathing still works, just no animation.

### Custom Challenge Builder Validation

- "Next" button (Step 1→2): disabled until Challenge Name has at least 1 non-whitespace character
- "Create Challenge" button (Step 2): disabled until Goal Type inputs are complete:
  - Streak: always valid (default 30 days)
  - Target: Goal Value field must be non-empty numeric
  - Date-Bound: end date must be in the future
- Validation errors: shown inline below the offending field as `.caption` in `Color.red`
- No full-screen error alerts for builder validation

### Buddy Ping

- Available once per 24-hour window per buddy — after ping, button shows "Ping Sent!" and is disabled until 24h elapses
- Ping mechanism: local `UNUserNotificationCenter` push to the app itself (no Contacts-framework push) — buddy accountability is motivational/self-reported, not a true remote push to the buddy's device in Phase 14
- This constraint must be documented in the builder "Privacy" row tooltip

### Tone Rules (inherits from Phase 13 / REQUIREMENTS.md UI-02)

- Warm and encouraging — never productivity-aggressive
- "Share Your Progress" not "Create Post"
- "Be the First to Share" not "No Posts Yet"
- "Staying spending-free" not "No Spending"
- "Stay Grounded" not "Distraction Tools"
- "Accountability Buddy" not "Accountability Partner" (shorter, friendlier)
- "Just Me" not "Private" — privacy option framing avoids privacy-anxiety connotation
- "Don't lose your streak!" (streak-at-risk) — mild urgency, not alarming
- Empty states: always include an action path ("Be the first to share...", "Add your first photo...")
- No red failure states in challenge UI (CHAL-25) — report outcome is silent removal, not red error
