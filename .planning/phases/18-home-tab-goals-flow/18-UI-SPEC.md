## Spacing Scale

Declared values (all multiples of 4 — mapped to SwiftUI `.padding` calls):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4pt | Icon gaps, capsule step-dot spacing (HStack spacing: 5 rounds to 4) |
| sm | 8pt | Sub-element spacing, section header sub-labels |
| md | 16pt | Default element padding (card inner padding top/bottom), goalRow vertical padding |
| lg | 24pt | Horizontal screen margins — `.padding(.horizontal, 24)` — primaryGoalCard internal padding |
| xl | 32pt | Bottom scroll spacer, sheet bottom padding |
| 2xl | 48pt | Bottom button safe-area padding on celebration screen |
| 3xl | 64pt | Not used in Phase 18 |

**Exceptions:**
- Touch targets: minimum 44pt height for all tappable rows and buttons (`.frame(minHeight: 44)`)
- Day grid cells: 36pt minimum touch target per cell (GOAL2-05 — date circles must be tappable)
- Choice screen path cards: 56pt minimum height per card (3-path entry sheet)

## Typography

All sizes and weights are absolute values for SwiftUI `.font()` modifiers. Exactly 4 sizes, 2 weights per font family.

| Role | Font | Size | Weight | Line Height / Notes | Source |
|------|------|------|--------|---------------------|--------|
| Display / step header | Cormorant Garamond | 34pt | Regular | lineSpacing: 2 | VGTheme.serif(34) — existing Step1 pattern |
| Section heading / card serif title | Cormorant Garamond | 20pt | SemiBold | lineLimit: 3 (card title) / default (section heading) | VGTheme.serif(20, weight: .semibold) |
| Body / stat numeric / quote italic | SF Pro / Cormorant Garamond Italic | 16pt | Regular | lineSpacing: 4 (quote card) / default elsewhere; serifItalic style is a variant of Regular weight, not a third weight | .font(.system(size: 16)) / VGTheme.serifItalic(16) |
| Label / supporting / caption / overline | SF Pro | 13pt | Regular or Semibold | Uppercase captions use kerning 1.2–1.4, .textCase(.uppercase); streak count uses .design(.monospaced) | .font(.system(size: 13)) |

**Cormorant Garamond weight constraint:** Regular (400) and SemiBold (600) only. Italic is a style variant of Regular — `VGTheme.serifItalic()` is Regular weight in italic style, not a separate weight entry. Medium weight is not used in Phase 18; any prior "Medium" usage maps to SemiBold.

**SF Pro weight constraint:** Regular (400) and Semibold (600) only.

**Component-local sizes (not named scale entries):** Sheet titles ("Start your goal", pre-made goals header) and celebration heading are rendered at 34pt Cormorant Regular or system equivalent — these reuse the Display scale entry and do not introduce additional named sizes.

## Color

All values reference VGTheme semantic tokens (adaptive light/dark). Raw hex shown for light mode.

| Role | VGTheme Token | Light Mode Hex | Usage |
|------|---------------|----------------|-------|
| Dominant surface (60%) | VGTheme.heroBackground | #3D2F1E (clay) | Home tab full-screen background — intentionally dark in both modes |
| Secondary surface (30%) | VGTheme.sandLight | #FAF5EE | Wizard step backgrounds (Step1–3), GoalEntryChoiceView sheet background |
| Cards / overlays | VGTheme.surface | #FDFAF6 (warmWhite) | Goal row cards, quote card, community goal card, Stats nav row |
| Frosted card (dark context) | Color.white.opacity(0.07) | — | Cards rendered on heroBackground (primary goal card pattern) |
| Accent — terra (10%) | VGTheme.accentTerra | #C4673A | Reserved for: streak badge, CTA buttons, progress bar fill (community goal), active step dot, quote card left border, "Open →" links, flame icon |
| Accent — sage | VGTheme.accentSage | #7A9E7E | Reserved for: "In progress" status pill, completed day circles in day grid |
| Accent — gold | VGTheme.accentGold | #C4A459 | Reserved for: 3+ day flame icon on goal rows (GOAL2-05) |
| Destructive | Color.red (system) | — | Delete goal confirmation only |
| Text primary | VGTheme.textPrimary | #3D2F1E (clay) | Body text on sand/light backgrounds |
| Text primary (dark surface) | VGTheme.sand | #F2E8D9 | Headings and body on heroBackground |
| Text secondary | VGTheme.textSecondary | clay @ 75% | Supporting text, card subtitles |
| Text muted | VGTheme.textMuted | #9A8A78 | Overlines, captions, chevrons, tier labels |
| Separator | VGTheme.separator | #E8D9C4 (sandMid) | Card borders (.strokeBorder lineWidth: 1) |
| Celebration overlay | Color.black.opacity(0.92) | — | CheckInCelebrationView full-screen cover background |

**Accent reservation rules:**
- `accentTerra` is the ONE interactive accent. It appears on: primary CTA buttons, streak badge, active state indicators, left-border quote accent, progress fill.
- `accentSage` is data-positive only: completed days, "In progress" badge.
- `accentGold` is streak-achievement only: flame icon on goals with 3+ consecutive days.
- Do NOT use accentTerra for decoration or secondary actions. Secondary/tertiary actions use `VGTheme.textMuted` or `VGTheme.textSecondary`.

## Interaction Contracts

### GoalEntryChoiceView Sheet
- Trigger: "+Add" button in My Goals section (Home) OR "+" in GoalListView
- Presentation: `.sheet` (SwiftUI default medium detent, not `.fullScreenCover`)
- Dismiss: swipe down OR selecting a path (sheet closes, then destination presents)
- Path routing:
  - "Need ideas" → push `PremadeGoalsListView` within sheet's `NavigationStack`
  - "Already have a goal" → dismiss sheet, present `GoalCreationWizardView(startAtStep: 1)` (skipping Step 1 category choice, or category choosable inline)
  - "Build my own goal" → dismiss sheet, present `GoalCreationWizardView()` from Step 1

### CheckInCelebrationView
- Trigger: user completes a goal check-in action in `GoalDetailView`
- Presentation: `.fullScreenCover`
- Auto-dismiss: `DispatchQueue.main.asyncAfter(deadline: .now() + 2.0) { dismiss() }`
- Manual dismiss: "Back to Goals" button — always present; calls `dismiss()`
- Post-dismiss: user returns to the view that presented it (GoalDetailView or GoalListView)
- Reduce motion: confetti canvas hidden; badge scales in statically at 0.3 → 1.0 without spring

### GoalDayGridView Month Navigation
- Default: current calendar month
- Navigation: leading/trailing chevron.left / chevron.right SF Symbol buttons with `.accessibilityLabel("Previous month")` and `.accessibilityLabel("Next month")` respectively
- Cannot navigate past current month into future
- Cannot navigate before goal's `startDate` month
- State: `@State private var displayedMonth: Date` — local to GoalDetailView or GoalDayGridView
- No swipe gesture required (chevrons are sufficient per CONTEXT.md discretion note)

### Flame Icon on Goal Rows (D-11)
- Condition: per-goal consecutive day streak >= 3 (calculated by StreakEngine against CompletionEvent records)
- Placement: trailing slot of goalRow HStack, before chevron.right
- Animation: none (static glyph)
- Accessibility: `.accessibilityLabel("{N} day streak — on fire!")`

## Notes for Executor

1. **No new files for shadcn** — this is a pure SwiftUI project. All "design tokens" are `VGTheme.*` references.
2. **VGTheme.heroBackground** is intentionally dark in both light and dark modes — all text on the Home dashboard uses `VGTheme.sand` (not `VGTheme.textPrimary`) for legibility.
3. **Confetti implementation** — use the existing `MilestoneCelebrationView` confetti pattern (SwiftUI Canvas + TimelineView, 60 particles, golden-angle scatter). Do not introduce SpriteKit or third-party animation libraries.
4. **StreakEngine** — the streak count shown in the Home header and the celebration screen is the **overall app streak** (longest or current streak across all goals), not a per-goal value. Source from `StreakEngine`.
5. **GoalDayGridView** — `LazyVGrid` with 7 columns and `GridItem(.fixed(36))` ensures uniform 36pt circles. Use `Date` arithmetic to populate only days within the current displayed month; pad leading cells for the week offset of the 1st.
6. **Accessibility** — every interactive element must have `.accessibilityLabel`. Confetti and decorative elements use `.accessibilityHidden(true)`.
7. **Preserved spacing values (not design tokens):** The existing `goalRow` pattern uses 14pt vertical padding and the existing `primaryGoalCard` pattern uses 22pt internal padding. These are legacy implementation values — do NOT create named design tokens for them. Preserve them in code as literal constants (`14`, `22`) to maintain visual consistency with existing rendered cards. Do not list them in the spacing scale or exceptions table.
