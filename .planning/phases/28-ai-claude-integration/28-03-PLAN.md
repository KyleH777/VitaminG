<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| AIViewModel ← SwiftData @Query | Goals and completion events flow from local SwiftData store (treated as untrusted input boundary per CLAUDE.md) into the AI fetch payload |
| AIMotivationSection → SwiftUI Text | Claude-generated text is rendered via SwiftUI Text() — no HTML, no JS execution surface |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-28-10 | Tampering | Claude-generated motivation text shown in SwiftUI | mitigate | SwiftUI `Text()` renders plain text; no HTML/JS execution. Even if Claude returns markup, it displays as literal characters. |
| T-28-11 | Information Disclosure | Goal titles in fetch payload | accept | Goal titles are already CloudKit-synced user content. Payload sent to Worker (and onward to Anthropic) is the same data the user already entered. Documented acceptance in RESEARCH.md Security Domain. |
| T-28-12 | Denial of Service | View blocked on slow Worker response | mitigate | `URLRequest.timeoutInterval = 10` (Plan 02) bounds wait. While loading, `.redacted(reason: .placeholder)` shows; on timeout, fallback fills silently — view never blocks. |
| T-28-13 | Spoofing | UserDefaults cache key tampering | accept | Only the app process writes/reads its own UserDefaults under a sandboxed bundle ID. No cross-app tampering surface on iOS. |
</threat_model>
