# Phase 28: AI (Claude) Integration - Context

**Gathered:** 2026-06-06
**Status:** Ready for planning

<domain>
## Phase Boundary

Wire Claude-powered content into two existing screens via a Cloudflare Worker proxy:

1. **Home tab** — Replace the existing `quoteSection` ("TODAY'S DOSE") with a personalized daily motivation message generated by Claude using the user's streak count and active goal titles. Falls back to VGQuoteBank when the proxy is unreachable. Label changes to "YOUR DOSE" when Claude copy is available.

2. **Explore tab** — Add a "Goals suggested for you" card (section label: "GOALS FOR YOU") in the second position (between "Today's Gift" and "Daily Mood") with 3 Claude-generated goal suggestions based on the user's existing goal titles and categories. Tapping a suggestion adds it as a QuickWin-tier goal; the suggestion gets marked with a checkmark/dimmed state (not removed). Falls back to 3 static generic suggestions when proxy is unreachable.

3. **Cloudflare Worker proxy** — Single endpoint at a stable HTTPS URL. iOS POSTs structured payloads; Worker builds Claude prompts server-side; Worker returns thin JSON responses. The Anthropic API key never appears in the iOS binary.

All AI features cache one Claude response per calendar day (UserDefaults, date-string key). Primary trigger is app foreground + date-cache miss. BGAppRefreshTask is a non-deterministic fallback only.

</domain>

<decisions>
## Implementation Decisions

### Motivation Card (Home Tab — AI-02)

- **D-01:** The existing `quoteSection` at `HomeView.swift:173` is REPLACED by the AI motivation section. Same card position, same visual shell. When Claude copy is available, section label is "YOUR DOSE"; when falling back to VGQuoteBank, label is "TODAY'S DOSE". No separate card is added — one slot, two copy sources.
- **D-02:** Copy format: 2–3 sentences, warm and personal (≤40 words). The prompt to Claude must constrain length. References the user's streak count and active goal titles per AI-02. The existing card shell uses `fixedSize(horizontal: false, vertical: true)` so it accommodates paragraph copy without layout changes.
- **D-03:** Caching: UserDefaults key is the calendar date string (e.g., `"vg_motivation_2026-06-06"`). At most one Claude call per calendar day. On fallback, VGQuoteBank fills the same slot — the user never sees an empty card or error state.

### Goal Suggestions Card (Explore Tab — AI-01)

- **D-04:** The "Goals suggested for you" card appears in the **second position** in the Explore scroll — between "Today's Gift" (GoalGifterCard) and "Daily Mood" (MoodPromptCard). Section label: "GOALS FOR YOU" (all-caps, matching existing section label style).
- **D-05:** Tapping a suggestion adds the goal as **QuickWin tier** immediately (single-tap, per AI-01). The tapped suggestion is marked as added (checkmark or dimmed appearance) — the card stays visible with all 3 suggestions; added ones are visually distinguished.
- **D-06:** Caching: UserDefaults key is the calendar date string (e.g., `"vg_suggestions_2026-06-06"`). Suggestions do not re-fetch more than once per day.
- **D-07:** Fallback when Worker is unreachable: Show 3 static pre-written suggestions (e.g., "Read for 15 minutes daily", "Drink 8 glasses of water", "Meditate for 5 minutes"). Card is always present — no error state, no hidden card.

### Cloudflare Worker API Contract

- **D-08:** Single endpoint: `POST /ai`. Request body:
  ```json
  {
    "type": "motivation" | "suggestions",
    "goals": [{ "title": "string", "category": "string" }],
    "streak": 14,
    "token": "<shared-secret>"
  }
  ```
  The `token` field is a UUID-format shared secret compiled into iOS as a constant (not the Anthropic key — acceptable to embed). Worker validates the token before forwarding to Claude.

- **D-09:** Response format (thin JSON wrapper, not raw Claude API response):
  - Motivation: `{ "text": "Your personalized message here." }`
  - Suggestions: `{ "suggestions": ["Suggestion 1", "Suggestion 2", "Suggestion 3"] }`
  The Worker extracts `content[0].text` from Claude's response, wraps it, returns the thin envelope. iOS never parses Claude's API schema directly.

- **D-10:** Worker builds Claude prompts server-side from the structured payload. iOS sends structured data only — prompts can be iterated without app updates.

- **D-11:** Worker auth: simple shared secret (UUID-format) sent as a field in the request body. Deters casual abuse if the Worker URL is discovered. The Anthropic API key exists ONLY in the Worker's Cloudflare environment variables.

### Claude's Discretion

- **Motivation copy format** — 2–3 sentences, ≤40 words, warm and personal. Claude (implementing agent) should craft the Claude prompt to produce this format. The card's `fixedSize` layout accommodates variable paragraph length.
- **Worker token storage on iOS** — Store the shared-secret UUID as a `private static let` constant in the `AIProxyService` (or equivalent service). It is a rate-limiting token, not a credential that grants data access — embedding as a constant is acceptable.
- **Claude model and max_tokens** — Implementing agent should use `claude-haiku-4-5-20251001` (fast, low-cost) for both endpoints. `max_tokens: 150` for motivation, `max_tokens: 200` for suggestions (3 short goal titles). Worker sets these.

</decisions>

## Existing Code Insights

### Reusable Assets
- `VGQuoteBank.swift` — Direct fallback for motivation copy. `VGQuoteBank.all` with day-of-year rotation is the exact existing logic — reuse verbatim as the fallback path.
- `quoteSection` in `HomeView.swift` — The card shell (background, left border accent, typography) is reused as-is. Only the copy source changes from VGQuoteBank to the `AIProxyService`.
- `GoalGifterCard.swift` — Reference for Explore card layout style and how a card adds a goal to the SwiftData model context.
- `WatchSessionManager.swift` — Singleton service pattern to copy for `AIProxyService`.

### Established Patterns
- **UserDefaults caching with date-string key** — `"vg_explore_gifterDate"` in GoalGifterCard uses `Calendar.current.isDateInToday()` pattern; Phase 28 uses date string keys (`"vg_motivation_YYYY-MM-DD"`, `"vg_suggestions_YYYY-MM-DD"`) for once-per-day gating.
- **@Observable ViewModels** — All ViewModels in this codebase use `@Observable` (not `ObservableObject`). `AIProxyService` or ViewModel managing AI state must follow this pattern.
- **No SchemaV11** — All AI state (cached motivation copy, cached suggestions, cache date key) lives in UserDefaults. Zero SwiftData model changes required.
- **BGAppRefreshTask** — Already used elsewhere as fallback; for AI motivation, primary trigger is app-foreground date-cache miss. Do not rely on BGAppRefreshTask as primary delivery.

### Integration Points
- `HomeView.quoteSection` → replace with AI motivation section driven by `AIProxyService`
- `ExploreView.existingScrollContent` → insert "GOALS FOR YOU" card between Section 1 (GoalGifterCard) and Section 2 (MoodPromptCard)
- Goal add-on-tap → calls same goal-creation path as GoalGifterCard (insert into modelContext with QuickWin tier)
- `StreakEngine.currentStreak(from:)` → source for streak count sent to Worker
