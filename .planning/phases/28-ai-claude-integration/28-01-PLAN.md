## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| iOS → Worker (HTTPS) | Untrusted client sends JSON body with goal titles, streak, and shared-secret token over TLS |
| Worker → Anthropic API (HTTPS) | Worker authenticates to Anthropic with `X-Api-Key`; key sourced from Cloudflare env (encrypted at rest) |
| Worker ← `env.ANTHROPIC_API_KEY` | Cloudflare runtime injects secret at request time; secret never persisted in Worker source or wrangler.toml |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-28-01 | Information Disclosure | Anthropic API key | mitigate | Key stored ONLY via `wrangler secret put ANTHROPIC_API_KEY` — encrypted Cloudflare secret. Worker source references `env.ANTHROPIC_API_KEY` and never a string literal. Worker `.gitignore` excludes `.dev.vars` and `.wrangler/`. Acceptance criterion: `grep -r "sk-ant-" worker/` returns 0. |
| T-28-02 | Elevation of Privilege | Worker /ai endpoint | mitigate | Shared-secret UUID token validated as the first action after JSON parse: `if (body.token !== SHARED_TOKEN) return 401`. Token is not the Anthropic key (D-11); deters casual abuse if the Worker URL is discovered. Anthropic call is gated by this check. |
| T-28-03 | Denial of Service | CORS preflight rejection | mitigate | OPTIONS preflight returns 204 with `Access-Control-Allow-Origin: *`, `Access-Control-Allow-Methods: POST, OPTIONS`, `Access-Control-Allow-Headers: Content-Type`. All success and error responses also include the Allow-Origin header so iOS URLSession does not reject. |
| T-28-05 | Tampering | Suggestions cache | mitigate | Wave 0 RED test (`test_fetchSuggestions_cacheHit_returnsCachedArray`) asserts the suggestions cache round-trips through `JSONEncoder().encode` to `Data` (not raw `set([String], forKey:)`), per Pitfall 1. Plan 02 implementation must conform to this contract. |
| T-28-SC | Tampering | `npm`/`npx wrangler` install | mitigate | `wrangler` is verified in RESEARCH.md Package Legitimacy Audit as the official Cloudflare CLI from `github.com/cloudflare/workers-sdk`. Task 3 human checkpoint is `blocking-human` (no auto-approval) to ensure the operator confirms the npm package identity before deploying. No iOS-side npm dependencies are added. |
| T-28-06 | Input Validation | Worker request body | mitigate | Worker validates `body.type` is exactly `"motivation"` or `"suggestions"` (else 400). Worker validates `body.token === SHARED_TOKEN` (else 401). Worker validates `body.goals` is an array (defaults to `[]` if missing). Worker validates `body.streak` is a number (defaults to 0). |
| T-28-07 | Tampering | Claude suggestions JSON | mitigate | Worker strips markdown code fences before `JSON.parse(text)` (Pitfall 5). If parse fails or array length < 3, Worker returns the 3 static fallbacks; iOS receives a well-formed response in either case. |
</threat_model>
