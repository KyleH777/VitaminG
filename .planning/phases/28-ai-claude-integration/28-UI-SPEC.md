## Spacing Scale

Declared values (SwiftUI points — multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4pt | VStack row sub-label gap (e.g. label + subtitle at spacing: 2–4) |
| sm | 8pt | Suggestion row internal leading/trailing breathing room |
| md | 16pt | Card internal VStack spacing (matches GoalGifterCard `spacing: 16`) |
| lg | 16pt | Card internal padding — `.padding(16)` (slight deviation from GoalGifterCard's 18pt to maintain grid compliance) |
| xl | 24pt | Screen horizontal padding — `.padding(.horizontal, 24)` |
| 2xl | 20pt | Top padding above quote section — `.padding(.top, 20)` |
| 3xl | 8pt | Label-to-body gap within motivation card — `spacing: 8` |

Exceptions:
- Motivation card top padding: 20pt (`.padding(.top, 20)`) — matches existing `quoteSection` exactly; not a standard multiple of 4 but preserved from existing implementation.
- GoalGifterCard corner radius: 20pt; motivation/suggestion cards: 14pt — both are established existing values; do not alter.
- Suggestion row vertical padding: 16pt top + 16pt bottom (`.padding(.vertical, 16)`) — 32pt padding + row text height exceeds 44pt iOS HIG minimum touch target requirement.
- Note: GoalGifterCard uses `.padding(18)` internally. `GoalSuggestionsCard` uses `.padding(16)` to comply with the 4-point grid. The visual difference is 2pt and is acceptable.

## Typography

All sizes in SwiftUI points (pt).

| Role | Font Helper | Size | Weight | Line Spacing / Other |
|------|-------------|------|--------|----------------------|
| Card micro-label | `.system(size:weight:)` | 9pt | `.semibold` | `.kerning(1.4)`, `.textCase(.uppercase)` — matches existing "TODAY'S DOSE" label |
| Suggestion body text | `.system(size:weight:)` | 16pt | `.regular` | `.lineSpacing(4)`, `.fixedSize(horizontal: false, vertical: true)` |
| Suggestion added-state caption | `.system(size:weight:)` | 14pt | `.regular` | foreground: `VGTheme.textMuted` |
| Motivation copy body | `VGTheme.serifItalic(16)` | 16pt | italic regular (CormorantGaramond-Italic) | `.lineSpacing(4)`, `.fixedSize(horizontal: false, vertical: true)` — matches existing card shell |
| Card header title (Explore card) | `VGTheme.serif(20)` | 20pt | `.regular` (CormorantGaramond-Regular) | matches GoalGifterCard "Shake out some growth" |

Typography rules:
- Never introduce a new font size in this phase. Use only sizes already declared above.
- The 9pt semibold uppercase label style is used ONLY for card micro-labels (card-internal provenance labels). It is not used for section labels.
- Section labels use the existing `sectionLabel(_:)` helper in ExploreView — do not replicate inline.

## Component Specs

### 1. Motivation Card (Home Tab — replaces `quoteSection`)

**File to modify:** `HomeView.swift` — replace `quoteSection` computed var in-place.

**Shell:** Identical to existing `quoteSection`. No layout changes.

```
VStack(alignment: .leading, spacing: 8)
  ├─ Text(label)                     // micro-label — "YOUR DOSE" or "TODAY'S DOSE"
  │   font: .system(size: 9, weight: .semibold)
  │   kerning: 1.4
  │   textCase: .uppercase
  │   foreground: VGTheme.textMuted
  └─ Text(motivationCopy)            // body copy from Claude or VGQuoteBank
      font: VGTheme.serifItalic(16)
      foreground: VGTheme.textSecondary
      lineSpacing: 4
      fixedSize(horizontal: false, vertical: true)

Card modifiers (outer):
  .padding(.horizontal, 18)
  .padding(.vertical, 16)
  .frame(maxWidth: .infinity, alignment: .leading)
  .background(VGTheme.surface)
  .overlay(alignment: .leading) { Rectangle().frame(width: 2).foregroundStyle(VGTheme.accentTerra) }
  .clipShape(RoundedRectangle(cornerRadius: 14))
  .padding(.horizontal, 24)
  .padding(.top, 20)
```

Note: The `.padding(.horizontal, 18)` on the card outer horizontal is preserved from the existing `quoteSection` shell to avoid visual regression in HomeView. The `lg` token (16pt) applies to new card construction in GoalSuggestionsCard.

**Label states:**
- Claude copy available: label = "YOUR DOSE"
- VGQuoteBank fallback active: label = "TODAY'S DOSE"

**Loading skeleton (while awaiting Claude response on first app open of the day):**
- Label: "YOUR DOSE" (always shown immediately; copy source resolves async)
- Body: Redacted placeholder — two lines of `.redacted(reason: .placeholder)` with width matching typical copy length
- Duration: shown only until the async fetch resolves OR cache hit is found; typical latency target < 1s with Haiku model
- Fallback triggers immediately on network error or timeout — never shows an empty card

**Dark mode note:** HomeView always renders on `VGTheme.heroBackground` (always dark clay/ink). `VGTheme.surface` in dark mode is a frosted warm tint (4.5% opacity). `VGTheme.textSecondary` and `VGTheme.textMuted` resolve to their dark-mode sand variants. Card is legible on dark background without any additional overlay.

**Accessibility:**
- `.accessibilityLabel("Daily motivation: \(motivationCopy)")` on the body Text
- `.accessibilityLabel("Today's dose section")` on the enclosing VStack

### 2. Goal Suggestions Card (Explore Tab — new card)

**File to create:** `GoalSuggestionsCard.swift` (new SwiftUI View)

**Position in ExploreView:** Second in `existingScrollContent` VStack — between `GoalGifterCard` (Section 1) and `MoodPromptCard` (Section 2). Preceded by `sectionLabel("GOALS FOR YOU")`.

**Section label:** "GOALS FOR YOU" — passed to existing `sectionLabel(_:)` helper. The helper renders it with consistent font treatment matching all other section labels in ExploreView.

**Card shell** (matches GoalGifterCard outer structure):

```
VStack(alignment: .leading, spacing: 16)
  ├─ Header row
  │   HStack(alignment: .center, spacing: 12)
  │     ├─ Icon: Image(systemName: "sparkles")
  │     │   font: .system(size: 22)
  │     │   foreground: VGTheme.accentTerra
  │     │   frame(width: 48, height: 48)
  │     └─ VStack(alignment: .leading, spacing: 2)
  │         ├─ Text("Goals suggested for you")
  │         │   font: VGTheme.serif(20)
  │         │   foreground: VGTheme.textPrimary
  │         └─ Text("Based on your goals and interests")
  │             font: .system(size: 14)
  │             foreground: VGTheme.textMuted
  └─ Suggestion rows (VStack, spacing: 0)
      ForEach(suggestions) { suggestion in SuggestionRow }

Card outer modifiers:
  .padding(16)
  .background(
    LinearGradient(
      colors: [VGTheme.accentTerra.opacity(0.12), VGTheme.accentTerra.opacity(0.04)],
      startPoint: .top, endPoint: .bottom
    )
  )
  .clipShape(RoundedRectangle(cornerRadius: 20))
  .overlay(RoundedRectangle(cornerRadius: 20).strokeBorder(VGTheme.accentTerra.opacity(0.2), lineWidth: 1))
  .padding(.horizontal, 16)
```

**Suggestion row layout (per row):**

```
HStack(alignment: .center, spacing: 12)
  ├─ Text(suggestion.title)
  │   font: .system(size: 16)        // unselected state
  │   foreground: VGTheme.textPrimary (unselected) / VGTheme.textMuted (added)
  │   lineSpacing: 4
  │   fixedSize(horizontal: false, vertical: true)
  │   frame(maxWidth: .infinity, alignment: .leading)
  └─ AddButton (trailing)

Row modifiers:
  .padding(.vertical, 16)           // 44pt+ touch target
  .contentShape(Rectangle())        // full-row tap area

Divider between rows: Divider().foregroundStyle(VGTheme.separator)
  (shown between rows, not after the last row)
```

**AddButton — unselected state:**

```
Button { addSuggestion(suggestion) } label: {
    Text("Add Goal")
        .font(.system(size: 14, weight: .semibold))
        .foregroundStyle(.white)
        .padding(.horizontal, 16)
        .padding(.vertical, 8)
        .background(VGTheme.accentTerra)
        .clipShape(Capsule())
}
.buttonStyle(.plain)
.accessibilityLabel("Add goal: \(suggestion.title)")
```

**AddButton — added state (after tap):**

```
Image(systemName: "checkmark.circle.fill")
    .font(.system(size: 24))
    .foregroundStyle(VGTheme.accentSage)
    .frame(width: 60, height: 32)
    .accessibilityLabel("Added")
```

Added suggestion row text: foreground shifts to `VGTheme.textMuted`. No strikethrough. Row is not tappable again.

**Loading skeleton (while awaiting Claude suggestions):**
- Header row: rendered normally
- Suggestion rows: 3 rows of `.redacted(reason: .placeholder)` with approximate widths (200pt, 170pt, 220pt)
- Fallback state: identical layout with 3 static suggestion titles substituted — no error indicator, no empty state

**Fallback suggestions (static, shown when Worker unreachable):**
1. "Read for 15 minutes daily"
2. "Drink 8 glasses of water"
3. "Meditate for 5 minutes"

**Fallback state visual contract:** Indistinguishable from Claude-generated content. No badge, no error label, no UI differentiation. The card is always visible with exactly 3 rows.

**Interaction — tap to add:**
- Single tap on "Add Goal" button adds goal as QuickWin tier via same model context path as GoalGifterCard
- `UIImpactFeedbackGenerator(style: .medium).impactOccurred()` on successful add
- No sheet, no confirmation — immediate add
- Button transitions to checkmark state with `.animation(.easeInOut(duration: 0.2))`
- Card stays visible; all 3 rows remain

**Search branch:** The AI suggestions card must NOT appear when `isSearching == true`. It is part of `existingScrollContent` which is already gated — no additional guard needed.

**Accessibility:**
- `.accessibilityLabel("Goals suggested for you, \(suggestions.count) suggestions")` on card VStack
- Individual rows: `accessibilityLabel("Suggestion: \(title)")`; button: `"Add goal: \(title)"` / `"Goal added: \(title)"`

## Interaction Contract

### Motivation Card

| Trigger | Behavior |
|---------|----------|
| App foreground, date-cache miss | `AIProxyService` fetches motivation from Worker async; skeleton shown during fetch; on success card displays Claude copy with "YOUR DOSE" label; on failure VGQuoteBank fills silently with "TODAY'S DOSE" label |
| App foreground, date-cache hit | Cached copy rendered immediately from UserDefaults — no network call; no visible loading state |
| Network timeout / Worker error | Falls back to `VGQuoteBank.all` day-of-year rotation; card displays "TODAY'S DOSE" label; no user-visible error |
| Tap on card | No action — card is read-only |

### Goal Suggestions Card

| Trigger | Behavior |
|---------|----------|
| ExploreView opens, date-cache miss | Fetch suggestions from Worker async; 3-row skeleton shown; on success rows populated with Claude suggestions |
| ExploreView opens, date-cache hit | 3 cached suggestions rendered immediately — no network call |
| Worker unreachable | 3 static fallback suggestions substituted immediately |
| Single tap "Add Goal" button | Add goal as QuickWin tier to modelContext; haptic feedback (medium impact); button state transitions to `checkmark.circle.fill` in `VGTheme.accentSage`; suggestion text foreground shifts to `VGTheme.textMuted`; animation: `.easeInOut(duration: 0.2)` |
| Tap already-added row | No action — row is non-interactive once added |
| isSearching == true | Card not shown (part of gated `existingScrollContent`) |

### State Transitions (Suggestions Row)

```
.unselected → [tap Add Goal] → .adding (haptic) → .added (checkmark shown, text muted)
.added → no further transitions (terminal state for the day)
```

### Caching Protocol

| Feature | UserDefaults Key Pattern | Cache Hit Check |
|---------|--------------------------|-----------------|
| Motivation copy | `"vg_motivation_YYYY-MM-DD"` | Key exists for today's date string |
| Suggestions | `"vg_suggestions_YYYY-MM-DD"` | Key exists for today's date string |

Both caches reset naturally when the date changes (new key each day). No explicit expiry needed.

## Implementation Notes for Executor

1. `quoteSection` in `HomeView.swift` is replaced in-place. The card shell SwiftUI markup is reused verbatim. Only the copy source and label string change based on `AIProxyService` state. The VStack spacing changes from 6 to 8 (`spacing: 8`) for grid compliance.

2. `GoalSuggestionsCard.swift` follows `GoalGifterCard.swift` as a structural reference. The outer card shell (padding, background gradient, clipShape, overlay, horizontal padding) is modeled after GoalGifterCard but uses `.padding(16)` instead of GoalGifterCard's `.padding(18)` to maintain 4-point grid compliance.

3. `ExploreView.existingScrollContent` receives two new lines between Section 1 and Section 2:
   ```swift
   sectionLabel("GOALS FOR YOU")
   GoalSuggestionsCard(viewModel: aiViewModel)
   ```
   These lines must NOT appear inside `isSearching` branches.

4. The `AIProxyService` singleton follows the `WatchSessionManager.swift` pattern (`.shared`, activated at app startup, `@Observable`).

5. `WidgetDataProvider.build()` output is used to source goal titles and streak count for the Claude prompt payload — consistent with the established single source of truth.

6. No SwiftData schema changes. All AI state lives in UserDefaults.

7. Button label is "Add Goal" (not "Add") throughout all implementation. The visible label `Text("Add Goal")` and accessibility label `"Add goal: \(suggestion.title)"` are both required.
