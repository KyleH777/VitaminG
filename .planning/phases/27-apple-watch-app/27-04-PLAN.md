<objective>
Implement the accessoryRectangular WidgetKit complication for watchOS. This is the user-visible WATCH-02 surface: the complication on the watch face that shows the active goal title and progress ring. It reads exclusively from the Watch App Group UserDefaults that Plan 03's `WatchReceiver` populates after each WCSession push from the iPhone.

Purpose: With Plans 02 + 03 the iPhone pushes snapshots and the Watch app's TodayGlanceView reflects them — but the complication is the primary "glance at wrist" surface called out in WATCH-02's Goal statement and the milestone success criterion. Without this widget extension, the user can't pin Vitamin G to a watch face.

Output: A working accessoryRectangular complication renders correctly from the Watch App Group UserDefaults, with two layout states (active vs. checked-in). Visual verification on Simulator confirms the layout (full E2E across WCSession remains a physical-device gate in Plan 06).
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Watch Widget Extension process ↔ Watch app process | Both signed with the same Team ID; share App Group container via entitlement |
| UserDefaults(suiteName:) read in TimelineProvider | Receives whatever the Watch app most-recently wrote; no validation of payload provenance |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-27-04-01 | Tampering | UserDefaults read in widget extension | accept | App Group access is gated by code signing; only legitimate Vitamin G processes can write — same as existing iOS widget threat model |
| T-27-04-02 | Information Disclosure | Goal title on watch face | accept | User explicitly added the complication to their face; visibility is the intended behavior; title contains no PII beyond what the user authored |
| T-27-04-03 | Denial of Service | UserDefaults nil suite | mitigate | TimelineProvider falls back to default zero values when defaults is nil; complication shows "No active goal" rather than crashing |
| T-27-04-04 | Tampering | Missing containerBackground | mitigate | Acceptance grep requires `containerBackground` token; without it, watchOS 10 rejects the widget render |
</threat_model>
