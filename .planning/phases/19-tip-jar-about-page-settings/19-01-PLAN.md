| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-19-01-01 | Tampering | `vg_colorScheme` UserDefaults value | mitigate | `@AppStorage` with RawRepresentable enum falls back to the default `.system` case on any unknown raw value (Plan 02 consumes this); raw values are stable lowercase strings, never changed after ship |

| T-19-01-SC | Tampering | npm/pip/cargo installs | mitigate | No package-manager installs in this phase — all native Apple frameworks (StoreKit, SwiftUI, XCTest); no slopcheck applicable |
