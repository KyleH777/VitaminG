`ColorSchemePreference` to the entire app via `.preferredColorScheme()` on the WindowGroup root, (2) install a
long-lived `StoreKit.Transaction.updates` listener at `init()` so out-of-band IAP transactions are finished,
and (3) reschedule the daily reminder on launch so existing users pick up the new rotating notification copy

works when `.preferredColorScheme()` is on the WindowGroup root. MON-03 / D-08 lock the `Transaction.updates`
listener to `VitaminGApp.init`. The launch reschedule (19-RESEARCH.md Open Question 3) ensures Plan 05's copy
change reaches users who never open Settings.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| StoreKit servers <-> app | `Transaction.updates` delivers transactions signed by Apple; signature must be verified before any side effect |
| UserDefaults <-> app | `vg_colorScheme` raw string is read at launch — must not crash on an unknown value |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-19-02-01 | Tampering | Transaction.updates listener | mitigate | Switch on `VerificationResult`; act only on `.verified`; silently discard `.unverified` (a forged/tampered transaction) — never call `finish()` for unverified, never grant anything |
| T-19-02-02 | Spoofing | Forged in-app purchase | mitigate | StoreKit 2 verifies the JWS signature from Apple's servers automatically; the code never hand-rolls receipt validation (19-RESEARCH.md "Don't Hand-Roll") |
| T-19-02-03 | Tampering | `vg_colorScheme` UserDefaults value | accept | `@AppStorage` with the RawRepresentable enum falls back to `.system` on any unknown value; worst case is a cosmetic appearance reset — no security impact |
| T-19-02-04 | DoS | Transaction.updates Task leak | mitigate | Task stored as a `let` property on the App struct (lifetime-scoped); not a local var that would deallocate and stop processing the queue |
| T-19-02-SC | Tampering | npm/pip/cargo installs | mitigate | No package-manager installs — native StoreKit/SwiftUI/UserNotifications only; no slopcheck applicable |
</threat_model>
