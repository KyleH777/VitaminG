## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Active goals → notification body | User-provided goal titles flow into notification text; potentially adversarial content (oversized, control characters) |
| CompletionEvent array → StreakEngine | Untrusted SwiftData store flowing into streak computation; bad data could shift tone tier |
| 64-slot UNUserNotificationCenter queue | iOS hard limit; exceeding it silently drops requests |
| One-shot identifier reuse | `globalStreakAtRiskIdentifier` reused between Phase 23 repeating nudge (still alive) and Phase 25 one-shot — must remain at-most-one-pending |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|

| T-25-02-02 | Denial of Service | One-shot 7 PM scheduling consumes a notification slot every schedule() call, risking 64-slot exhaustion | mitigate | `scheduleOneShotStreakAtRisk` reuses `globalStreakAtRiskIdentifier` with remove-before-add (at-most-one-pending invariant); 60-slot cap guard returns early before any add |
