<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| UI input (DatePicker, banner buttons) → NotificationPreferences writes | User-driven, but Apply path uses the validated modal hour 0-23 from NotificationPreferences.modalCheckInHour() which already applies the security clamp |
| @Query collections → fire-and-forget Task closures | Risk of capturing SwiftData ManagedObject-equivalents that mutate or detach across the await boundary |
| App Group UserDefaults dismissed flag | Untrusted persisted bool — already mitigated by .bool(forKey:) in Plan 01 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
