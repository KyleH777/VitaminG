<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| HomeView → NavigationStack path | NavigationLink value (AppRoute) flows from a child view into the tab's NavigationStack and is resolved by the navigationDestination switch. The value is constructed inline at the call site, so no external input crosses this boundary. |
| navigationDestination switch | The switch consumes AppRoute values from any source that pushes onto the Home tab's NavigationStack. In this phase only HomeView pushes; in future phases deep links may push routes here. Defensive `default: EmptyView()` catch-all prevents unintended construction of unhandled view types. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-16-05 | Tampering | Stale deep link or widget intent encoded with old `.stats` / `.wins` location (Goals tab) | mitigate | This plan completes the migration of `.stats` and `.wins` from Goals-tab navigationDestination (already removed by Plan 01) to Home-tab navigationDestination. After this plan, pushing `AppRoute.stats` or `AppRoute.wins` is only meaningful on the Home tab's NavigationStack. Any prior code that pushed these onto the Goals tab path is now a no-op (falls through to the catch-all), which is a graceful degradation rather than a crash. |
| T-16-06 | Denial of Service | Tapping the Quick Stats row or Daily Wins entry crashes the app | mitigate | Both NavigationLinks push existing, already-shipped views (`StatsView`, `DailyWinsView`) with no required init arguments. The navigationDestination switch is exhaustive with a `default: EmptyView()` catch-all so an unexpected route value renders blank rather than crashing. |
| T-16-07 | Information Disclosure | Combined VoiceOver label includes user counts (active goals, check-ins, badges) | accept | Same data is already rendered visually in the Quick Stats row; the accessibilityLabel makes the existing visible information available to VoiceOver users. No new data surface introduced. |
| T-16-08 | Elevation of Privilege | None applicable | accept | No auth or permission state is read or modified in this plan. |
| T-16-SC | Tampering | npm/pip/cargo installs | accept | This phase introduces no new package-manager installs. The plan uses only `SwiftUI` and existing project types (`AppRoute`, `Tab`, `StatsView`, `DailyWinsView`, `VGTheme`), all first-party or already-shipped. |
</threat_model>
