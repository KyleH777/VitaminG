## States and Interactions

### PublicProfileView — State Machine

| State | Visual | Trigger |
|-------|--------|---------|
| `.loading` | Centered `ProgressView()` tinted warm orange, with caption "Loading profile…" | Sheet appears while CloudKit fetch is in progress |
| `.loaded(displayName:avatarColorHex:)` | AvatarView (72pt) + display name (`.title2.semibold`) centered vertically | CloudKit fetch returns a valid record |
| `.error(message)` | SF Symbol `exclamationmark.icloud.fill` (`.title` size, `.secondary` tint) + error message (`.body`) + Dismiss button | CloudKit throws or record is not found |

### Sheet Presentation

- Presented as `.sheet` over whatever tab is active — no tab switching, no push navigation (D-06).
- Sheet has a single navigation bar item: "Done" button (trailing, `.body.weight(.semibold)`, warm orange tint).
- Tapping "Done" sets `router.pendingPublicProfileRecordID = nil`, which dismisses the sheet.
- Sheet is not dismissible by drag during `.loading` state: wrap content in `.interactiveDismissDisabled(viewModel.isLoading)`.

### URL Parsing (VitaminGApp)

- Scheme check: `url.scheme == "vitaming"` — unknown schemes silently ignored.
- Host check: `url.host == "profile"` — unknown hosts silently ignored.
- RecordID extraction: `url.pathComponents.dropFirst().first` — must be non-empty to trigger navigation.
- On success: `router.pendingPublicProfileRecordID = recordID`.
- On failure (malformed URL): no action, no alert — silent drop per D-09.
