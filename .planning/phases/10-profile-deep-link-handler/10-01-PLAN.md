       ```swift
       import Foundation

       /// Parses incoming vitaming:// deep link URLs.
       /// Extracted as a pure static function so URL parsing is unit-testable
       /// without launching the full app or SwiftUI scene.
       enum DeepLinkParser {
           /// Extracts the recordID from a vitaming://profile/<recordID> URL.
           /// Returns nil for malformed, unknown, or empty URLs — caller silently ignores nil (D-09).
           static func recordID(from url: URL) -> String? {
               guard url.scheme == DeepLinkBuilder.scheme,
                     url.host == "profile",
                     let recordID = url.pathComponents.dropFirst().first,
                     !recordID.isEmpty else { return nil }
               return recordID
           }
       }
       ```
       This function references `DeepLinkBuilder.scheme` to avoid duplicating the "vitaming" string constant. The `pathComponents.dropFirst()` skips the leading "/" component. The `!recordID.isEmpty` guard handles trailing-slash URLs.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| External URL -> App | Untrusted URL from any source (Messages, Safari, malicious app) enters via .onOpenURL |
| App -> CloudKit public DB | recordID string from URL used to construct CKRecord.ID for network fetch |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-10-01 | Tampering | DeepLinkParser.recordID(from:) | mitigate | Guard: scheme == "vitaming", host == "profile", non-empty recordID. Only first path component used. Never passed to file system or SQL. Unit tests verify all malformed variants return nil. |
| T-10-02 | Information Disclosure | ProfileSharingService.fetchProfile | accept | CloudKit public database is intentionally public. Only displayName and avatarColorHex are stored — no PII beyond what user chose to share via publishProfile. |
| T-10-03 | Spoofing | vitaming:// URL scheme | accept | Custom URL scheme can be claimed by another app. Universal Links would mitigate but are out of scope (D-09 locks custom scheme). Risk is identical to Phase 7 send-side and accepted there. |
| T-10-04 | Tampering | PublicProfileView Text display | mitigate | SwiftUI Text() renders plain text, not HTML — no XSS equivalent. InputSanitizer.sanitizeForPublic was applied at publish time (Phase 7). |
| T-10-05 | Denial of Service | Repeated deep link taps | accept | Each tap triggers one CloudKit fetch. CloudKit has built-in rate limiting. No local resource exhaustion risk. |
</threat_model>
