## Spacing Scale

Widget canvas is constrained — use a reduced subset of the standard 4pt scale.

| Token | Value (pt) | Usage in this phase |
|-------|-----------|---------------------|
| xs | 4 pt | Icon-to-text gap within HStack (flame + count) |
| sm | 8 pt | VStack row spacing between streak row and goal row |
| md | 12 pt | Widget edge padding (`.padding(12)`) — matches current `GoalSummaryWidgetView` |
| lg | 16 pt | Not used in widget canvas |

Exceptions: Widget canvas does not support free-form layout padding above 16 pt. Keep all padding at 12 pt per existing `.containerBackground` pattern.

Source: Existing `GoalSummaryWidgetView` padding(12); CONTEXT.md D-01 "VStack(spacing: 8)"

### Widget Canvas Exceptions

**`md` token (12 pt) — formal project-level override:**
12 pt is the established widget edge padding for `GoalSummaryWidgetView` — matches existing `GoalSummaryWidget.swift` `.containerBackground` pattern. This value deviates from the standard 8pt/16pt scale and is approved for widget targets only. Approved for widget targets only. Do not use 12 pt as a spacing value outside of widget extension files.

## Typography

All fonts are system (San Francisco) unless noted. CormorantGaramond is the app's serif display font — **do not use in widgets** (custom fonts in widget extensions require explicit bundle configuration and add binary weight; SF system fonts are always available).

**Declared font weights: `.bold` and `.semibold` only.** `.regular` is the system default and requires no modifier — it is not a declared weight in this contract.

| Role | SwiftUI Font | Weight | Line Limit | Usage |
|------|-------------|--------|------------|-------|
| Streak count | `.title2.monospacedDigit()` | `.bold` | 1 | Streak number in top row |
| Streak label | `.caption` | `.semibold` | 1 | "day streak" label beside/below count |
| Goal title | `.subheadline` | `.semibold` | 1, `.truncationMode(.tail)` | Active goal title in bottom row |
| Flame icon | `.caption` size via Image | n/a | n/a | `flame.fill` SF Symbol in top row |
| Empty state | `.caption` | (default) | 2 | "Add your first goal" prompt |

Source: Existing `StreakWidgetView` (`.title2.bold().monospacedDigit()`, `.caption`) and `TierRowView` (`.subheadline`, `.fontWeight(.semibold)`); CONTEXT.md D-01

### Widget Color Contract (60/30/10)

| Role | Token | Approximate Split | Usage |
|------|-------|-------------------|-------|
| Dominant surface (60%) | `.containerBackground(.fill.tertiary, for: .widget)` | Widget background | Widget root background — required on all iOS 17+ widgets |
| Secondary surface (30%) | `VGTheme.textPrimary` / `VGTheme.textSecondary` | Primary text, labels | Streak count, goal title text |
| Accent (10%) | `VGTheme.accentTerra` | Progress bar fill + flame icon | Streak flame icon foreground; progress bar Capsule fill |

**Accent (`VGTheme.accentTerra`) is reserved for:**
1. `flame.fill` SF Symbol foreground color in streak top row
2. Progress bar `Capsule()` fill color

**Progress bar track (background):** `VGTheme.accentTerra.opacity(0.20)` — matches D-06 "accentTerra.opacity(0.20)"

**No destructive colors in this phase.** No delete, remove, or confirmation actions exist in a widget view.

## Layout Contract: `GoalSummaryWidgetView`

This is the primary visual deliverable of Phase 24.

### New Equal-Split Structure

```
┌─────────────────────────────────────────┐
│  [containerBackground: .fill.tertiary]  │
│  .padding(12)                           │
│                                         │
│  VStack(spacing: 8) {                   │
│                                         │
│    // TOP ROW — Streak                  │
│    HStack(spacing: 4) {                 │
│      Image("flame.fill")                │
│        .foregroundStyle(accentTerra)    │
│        .font(.caption)                  │
│      Text("\(streak)")                  │
│        .font(.title2.bold()             │
│             .monospacedDigit())         │
│      Text("day streak")                 │
│        .font(.caption)                  │
│        .fontWeight(.semibold)           │
│      Spacer()                           │
│    }                                    │
│                                         │
│    // BOTTOM ROW — Active Goal          │
│    VStack(alignment: .leading, spacing: 4) {
│      Text(activeGoalTitle)              │
│        .font(.subheadline)              │
│        .fontWeight(.semibold)           │
│        .lineLimit(1)                    │
│        .truncationMode(.tail)           │
│                                         │
│      // Progress bar (only if          │
│      // activeGoalProgress != nil)      │
│      GeometryReader { geo in            │
│        ZStack(alignment: .leading) {    │
│          Capsule()                      │
│            .fill(accentTerra.opacity(0.20))
│            .frame(height: 4)            │
│          Capsule()                      │
│            .fill(accentTerra)           │
│            .frame(width: geo.size.width │
│                   * progress,           │
│                   height: 4)            │
│        }                                │
│      }                                  │
│      .frame(height: 4)                  │
│    }                                    │
│  }                                      │
│                                         │
└─────────────────────────────────────────┘
```

**Progress bar height:** 4 pt (thin Capsule — not `.widgetAccentable()`)
**Progress bar width:** full available horizontal width via `GeometryReader` or `frame(maxWidth: .infinity)`

Source: CONTEXT.md D-01, D-06, Specifics section "VStack(spacing: 8) wraps both rows"

## States: `GoalSummaryWidgetView`

All states derive from `WidgetDisplayData` fields `globalStreak`, `activeGoalTitle`, `activeGoalProgress`.

| State | Condition | Top Row | Bottom Row |
|-------|-----------|---------|------------|
| **Nominal** | streak > 0, activeGoalTitle != nil, progress != nil | Flame + streak count + "day streak" | Goal title + progress bar |
| **No duration** | streak > 0, activeGoalTitle != nil, progress == nil | Flame + streak count + "day streak" | Goal title only (no bar rendered) |
| **No active goals** | streak > 0, activeGoalTitle == nil | Flame + streak count + "day streak" | "Add your first goal" in `.caption`, `.foregroundStyle(.secondary)` |
| **Empty / new user** | streak == 0, activeGoalTitle == nil | "Start your streak" in `.caption` | "Add your first goal" in `.caption` |
| **Placeholder/snapshot** | static | streak: 7, goal: "Meditate for 10 minutes", progress: 0.43 | Full nominal layout |

Source: CONTEXT.md Specifics "Empty state: 'Add your first goal' prompt", D-04 "nil = no duration, no bar"

## `WidgetDisplayData` Extension Contract

New fields to add to the `WidgetDisplayData` struct:

```swift
let activeGoalTitle: String?    // nil → no active goal exists
let activeGoalProgress: Double? // nil → goal has no durationDays; 0.0–1.0 clamped
```

Sentinel semantics:
- `activeGoalProgress == nil` → do NOT render a progress bar (not the same as 0% progress)
- `activeGoalProgress == 0.0` → render an empty progress bar (user has checked in 0 days)

`WidgetDisplayData.placeholder` must add:
```swift
activeGoalTitle: "Meditate for 10 minutes",
activeGoalProgress: 0.43
```

`WidgetDisplayData.empty` must add:
```swift
activeGoalTitle: nil,
activeGoalProgress: nil
```

Source: CONTEXT.md D-05

## Active Goal Selection Rule (D-03)

Implemented inside `WidgetDataProvider.build()`:

1. Filter goals: `!isCompleted`
2. Sort by tier priority: Immediate → Short Term → Long Term → Life Goal
3. Within same tier: sort by `creationDate` ascending (earliest first)
4. Select `.first` — that is the active goal
5. Compute progress: `Double(completionEvents.count) / Double(durationDays)`, clamped to `0.0...1.0`
6. If `durationDays == nil`, set `activeGoalProgress = nil`

Source: CONTEXT.md D-03, D-04

## WidgetKit Constraints (Non-Negotiable)

These are structural constraints, not design decisions. Executor must not deviate.

| Constraint | Rule |
|------------|------|
| `.containerBackground` | Must be `.containerBackground(.fill.tertiary, for: .widget)` on the root view — required iOS 17+ |
| Timeline policy | `Timeline(entries: [entry], policy: .never)` — push-only, do not change to `.atEnd` or `.after` |
| Placeholder / snapshot | Must use static `WidgetDisplayData.placeholder` — no SwiftData fetch allowed |
| `WidgetDataProvider` imports | Must remain pure (no SwiftUI / WidgetKit / SwiftData imports) |
| Thread safety | `WidgetDataProvider.build()` must remain a pure value computation — no `@MainActor` |
| Custom fonts in widget | Do not use `VGTheme.serif()` / CormorantGaramond — SF system fonts only |

Source: CONTEXT.md §Established Patterns; CLAUDE.md WidgetKit section
