# Plan 20-02: Mood Prompt Card

## Objective

Add the "How are you feeling?" once-per-day mood prompt card (EXPLORE-03) to `ExploreView`. After a mood chip is tapped, the card collapses with a checkmark animation and does not reappear until the next calendar day.

## Context

**Depends on:** Plan 20-01 (ExploreView scaffold, ExploreViewModel, ExploreModels.swift must exist).

**What exists after 20-01:**
- `VitaminG/VitaminG/VitaminG/Views/Explore/ExploreView.swift` — scroll layout with `GoalGifterCard` in Wave 1. This plan inserts `MoodPromptCard` below the gifter section.
- `VitaminG/VitaminG/VitaminG/ViewModels/ExploreViewModel.swift` — owns daily-gate state. This plan extends it with mood gate.
- `VitaminG/VitaminG/VitaminG/Models/ExploreModels.swift` — shared model types. This plan adds `MoodOption` enum.
- `VitaminG/VitaminG/VitaminGTests/ExploreViewModelTests.swift` — existing unit tests. This plan adds `testMoodGate`.

**Pattern to follow:**
- Collapsible card + dismiss: `Views/DailyWinsView.swift` lines 36–121 (once-per-day section header + save flow).
- Mood chip row: `Views/ChallengeDiscoveryView.swift` → `MoodScannerView` lines 217–237 (horizontal ScrollView of capsule chips).
- Card surface style: `.padding(18).background(VGTheme.surface).clipShape(RoundedRectangle(cornerRadius: 18)).overlay(RoundedRectangle(cornerRadius: 18).strokeBorder(VGTheme.separator, lineWidth: 1)).padding(.horizontal, 16)`.
- Section label: `.font(.system(size: 13, weight: .semibold)).kerning(0.4).foregroundStyle(VGTheme.textMuted).padding(.horizontal, 16)`.
- Reduce motion: always gate animations on `@Environment(\.accessibilityReduceMotion)`.

**Key constraints:**
- Daily gate: `UserDefaults.standard` key `"vg_explore_moodDate"` stores a `Date`. Check with `Calendar.current.isDateInToday(_:)`. This is a computed property in `ExploreViewModel` (not a stored property) to survive midnight.
- Do NOT use `SchemaV7.MoodEntry`. Do NOT call `context.insert` for mood. Do NOT create a SwiftData model for the mood prompt. UserDefaults only.
- Do NOT store the selected mood integer beyond the session. Only the date gate must persist. The requirement says the card collapses with a checkmark — the mood value does not need to be remembered.
- Mood options: 5 cases matching the project's existing mood scale (Amazing, Good, Okay, Low, Push) — same labels used in `SchemaV7.MoodEntry.mood` documentation.
- Animation: card collapses with `.transition(.opacity.combined(with: .move(edge: .top)))` wrapped in `withAnimation(.easeOut(duration: 0.3))`. Under reduce motion, set state directly without animation.

**MoodOption enum placement:** Add to `ExploreModels.swift` (already exists after 20-01). Do not create a separate file.

enum MoodOption: String, CaseIterable, Identifiable {

    }
}

**MoodPromptCard.swift:**

```swift
import SwiftUI

struct MoodPromptCard: View {
    @Bindable var viewModel: ExploreViewModel
    @Environment(\.accessibilityReduceMotion) private var reduceMotion

    var body: some View {
        if !viewModel.hasMoodSelectedToday {
            cardContent
                .transition(.opacity.combined(with: .move(edge: .top)))
        }
    }

    private var cardContent: some View {
        VStack(alignment: .leading, spacing: 14) {
            // Header row
            HStack {
                Text("How are you feeling?")
                    .font(VGTheme.serif(18))
                    .foregroundStyle(VGTheme.textPrimary)
                Spacer()
                // Checkmark dismiss button (accessibility fallback — dismisses without selecting)
                Button {
                    dismiss()
                } label: {
                    Image(systemName: "checkmark.circle.fill")
                        .font(.system(size: 22))
                        .foregroundStyle(VGTheme.accentSage)
                }
                .frame(minWidth: 44, minHeight: 44)
                .accessibilityLabel("Dismiss mood prompt without selecting")
            }

            // Mood chip row
            ScrollView(.horizontal, showsIndicators: false) {
                HStack(spacing: 8) {
                    ForEach(MoodOption.allCases) { mood in
                        Button {
                            selectMood(mood)
                        } label: {
                            HStack(spacing: 4) {
                                Text(mood.emoji)
                                    .font(.system(size: 16))
                                Text(mood.rawValue)
                                    .font(.system(size: 14, weight: .medium))
                                    .fontDesign(.rounded)
                            }
                            .foregroundStyle(VGTheme.textPrimary)
                            .padding(.horizontal, 16)
                            .padding(.vertical, 8)
                            .background(VGTheme.background)
                            .clipShape(Capsule())
                            .overlay(Capsule().strokeBorder(VGTheme.separator, lineWidth: 1))
                        }
                        .buttonStyle(.plain)
                        .accessibilityLabel("\(mood.emoji) \(mood.rawValue)")
                    }
                }
                .padding(.horizontal, 2)
            }
        }
        .padding(18)
        .background(VGTheme.surface)
        .clipShape(RoundedRectangle(cornerRadius: 18))
        .overlay(
            RoundedRectangle(cornerRadius: 18)
                .strokeBorder(VGTheme.separator, lineWidth: 1)
        )
        .padding(.horizontal, 16)
    }

    private func selectMood(_ mood: MoodOption) {
        UIImpactFeedbackGenerator(style: .light).impactOccurred()
        if reduceMotion {
            viewModel.selectMood(mood)
        } else {
            withAnimation(.easeOut(duration: 0.3)) {
                viewModel.selectMood(mood)
            }
        }
    }

    private func dismiss() {
        // Dismiss via checkmark button without selecting a mood — still marks date gate
        UIImpactFeedbackGenerator(style: .light).impactOccurred()
        if reduceMotion {
            viewModel.selectMood(.okay)  // use .okay as the "dismissed without selection" sentinel
        } else {
            withAnimation(.easeOut(duration: 0.3)) {
                viewModel.selectMood(.okay)
            }
        }
    }
}
```
