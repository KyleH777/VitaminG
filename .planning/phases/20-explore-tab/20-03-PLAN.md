# Plan 20-03: Vitamin Shelf — Category Grid + Filtered Goal List

## Objective

Implement the Vitamin Shelf (EXPLORE-04): a 2×3 grid of 6 category cards (Body, Mind, Wellness, Money, Connection, Creative) that navigates to a filtered list of the user's own goals for that category via `NavigationLink`.

## Context

**Depends on:** Plan 20-01 (ExploreView scaffold and `sectionLabel` helper must exist).
**Parallel with:** Plan 20-02 (both modify `ExploreView.swift` by appending sections — coordinate the section order: gifter → mood → shelf → [trending/stuck in 20-04]).

**What exists after 20-01:**

- `VitaminG/VitaminG/VitaminG/Models/GoalCategory.swift` — `GoalCategory` enum with all 6 shelf cases + `.emoji` + `.subtitle` computed properties.

**Pattern to follow:**
- 2-column `LazyVGrid`: `ChallengeDiscoveryView.swift` → `VitaminShelfGrid` (lines 311–315). Use `LazyVGrid(columns: [GridItem(.flexible()), GridItem(.flexible())], spacing: 12)` with `.padding(.horizontal, 16)`.
- Section label: `.font(.system(size: 13, weight: .semibold)).kerning(0.4).foregroundStyle(VGTheme.textMuted).padding(.horizontal, 16)`.
- Card surface: `.padding(16).background(VGTheme.surface).clipShape(RoundedRectangle(cornerRadius: 16)).overlay(RoundedRectangle(cornerRadius: 16).strokeBorder(VGTheme.separator, lineWidth: 1))`.
- `@Query` goal filtering: use `allGoals.filter { $0.category == category.rawValue && !($0.isCompleted) }` in-memory. Do NOT use `#Predicate` — a full `@Query` with in-memory filter is sufficient and avoids SwiftData predicate compilation issues with optional String.
- Goal list: `GoalListView` style rows — title + `ProgressRingView` per row. Use `ProgressRingView(progress: ..., tier: .immediate, isCompleted: false, size: 32, strokeWidth: 3, glow: false)` from `Views/Components/ProgressRingView.swift`.
- Navigation: `NavigationLink(value: category)` pushed via the `NavigationStack` in `ContentView`. Register a `navigationDestination(for: GoalCategory.self)` either in `ExploreView` or in the `NavigationStack` block in `ContentView`. Use `ExploreView` to keep navigation logic local to the Explore tab.

**Key constraints:**
- Vitamin Shelf shows the user's own SwiftData goals — NOT community goals. Source: `@Query private var allGoals: [Goal]`, filtered by `category == category.rawValue` and `isCompleted == false`.
- Use exactly these 6 `GoalCategory` cases (no `.habit`, no `.other`): `.body`, `.mind`, `.wellness`, `.money`, `.connection`, `.creative`.
- Goal count badge on each card: display number of non-completed goals for that category.
- Category card layout: emoji (large, 28pt font) + category name + subtitle + goal count badge.
- `CategoryGoalListView` is the `NavigationLink` destination — a plain `View` (no new `NavigationStack`).
- In `CategoryGoalListView`, if the category has 0 goals, show an empty-state message: `"No \(category.rawValue) goals yet"` with a `"+ Add a goal"` Button that navigates to the goal creation flow (append `AppRoute.createGoal` to the navigation path, or present the sheet). Use `AppRoute.createGoal` if it exists in the project, otherwise skip the button and just show the empty message.
- VGTheme only — no hardcoded colors.

**Checking AppRoute for createGoal:** Read `VitaminG/VitaminG/VitaminG/Navigation/AppRoute.swift` before implementing to see what cases exist. Use an available route or omit the add button if no suitable route exists.

**VitaminShelfSection.swift:**

```swift
import SwiftUI
import SwiftData

/// The 6-category Vitamin Shelf grid. Each card shows the category emoji, name,
/// subtitle, and a badge with the count of the user's non-completed goals in that category.
/// Tapping a card pushes CategoryGoalListView via NavigationLink.
struct VitaminShelfSection: View {
    @Query private var allGoals: [Goal]

    /// The 6 Vitamin Shelf categories (GoalCategory subset — excludes .habit and .other).
    private let shelfCategories: [GoalCategory] = [
        .body, .mind, .wellness, .money, .connection, .creative
    ]

    var body: some View {
        LazyVGrid(columns: [GridItem(.flexible()), GridItem(.flexible())], spacing: 12) {
            ForEach(shelfCategories) { category in
                NavigationLink(value: category) {
                    categoryCard(category)
                }
                .buttonStyle(.plain)
            }
        }
        .padding(.horizontal, 16)
    }

    private func categoryCard(_ category: GoalCategory) -> some View {
        VStack(alignment: .leading, spacing: 8) {
            HStack {
                Text(category.emoji)
                    .font(.system(size: 28))
                Spacer()
                // Goal count badge
                let count = goalCount(for: category)
                if count > 0 {
                    Text("\(count)")
                        .font(.system(size: 12, weight: .semibold))
                        .foregroundStyle(.white)
                        .padding(.horizontal, 8)
                        .padding(.vertical, 4)
                        .background(VGTheme.accentTerra)
                        .clipShape(Capsule())
                }
            }
            Text(category.rawValue)
                .font(.system(size: 15, weight: .semibold))
                .fontDesign(.rounded)
                .foregroundStyle(VGTheme.textPrimary)
            Text(category.subtitle)
                .font(.system(size: 12))
                .foregroundStyle(VGTheme.textMuted)
                .lineLimit(2)
        }
        .padding(16)
        .background(VGTheme.surface)
        .clipShape(RoundedRectangle(cornerRadius: 16))
        .overlay(
            RoundedRectangle(cornerRadius: 16)
                .strokeBorder(VGTheme.separator, lineWidth: 1)
        )
    }

    private func goalCount(for category: GoalCategory) -> Int {
        allGoals.filter { $0.category == category.rawValue && !($0.isCompleted) }.count
    }
}
```

**CategoryGoalListView.swift:**

```swift
import SwiftUI
import SwiftData

/// Destination view for a Vitamin Shelf category card. Shows the user's non-completed
/// goals for the selected GoalCategory. No new NavigationStack — uses the existing
/// NavigationStack from ContentView.
struct CategoryGoalListView: View {
    let category: GoalCategory
    @Query private var allGoals: [Goal]
    @State private var goalVM = GoalViewModel()
    @Environment(\.modelContext) private var modelContext

    private var filteredGoals: [Goal] {
        allGoals.filter { $0.category == category.rawValue && !($0.isCompleted) }
    }

    var body: some View {
        Group {
            if filteredGoals.isEmpty {
                emptyState
            } else {
                List {
                    ForEach(filteredGoals) { goal in
                        goalRow(goal)
                            .listRowBackground(VGTheme.surface)
                            .listRowSeparatorTint(VGTheme.separator)
                    }
                }
                .listStyle(.plain)
                .scrollContentBackground(.hidden)
                .background(VGTheme.background)
            }
        }
        .navigationTitle("\(category.emoji) \(category.rawValue)")
        .background(VGTheme.background.ignoresSafeArea())
    }

    private func goalRow(_ goal: Goal) -> some View {
        HStack(spacing: 12) {
            // Progress ring using existing ProgressRingView component
            let events = goal.completionEvents ?? []
            let total = max(goal.durationDays ?? 30, 1)
            let progress = Double(events.count) / Double(total)
            ProgressRingView(
                progress: min(progress, 1.0),
                tier: goal.tier,
                isCompleted: goal.isCompleted,
                size: 36,
                strokeWidth: 3,
                glow: false
            )
            VStack(alignment: .leading, spacing: 2) {
                Text(goal.title ?? "Untitled goal")
                    .font(.system(size: 15, weight: .medium))
                    .foregroundStyle(VGTheme.textPrimary)
                    .lineLimit(2)
                Text(goal.frequency ?? "")
                    .font(.system(size: 12))
                    .foregroundStyle(VGTheme.textMuted)
            }
            Spacer()
        }
        .padding(.vertical, 8)
    }

    private var emptyState: some View {
        VStack(spacing: 16) {
            Text(category.emoji)
                .font(.system(size: 48))
            Text("No \(category.rawValue) goals yet")
                .font(VGTheme.serif(20))
                .foregroundStyle(VGTheme.textPrimary)
            Text("Add your first \(category.rawValue.lowercased()) goal to see it here.")
                .font(.system(size: 15))
                .foregroundStyle(VGTheme.textMuted)
                .multilineTextAlignment(.center)
                .padding(.horizontal, 32)
        }
        .frame(maxWidth: .infinity, maxHeight: .infinity)
        .padding(.top, 60)
    }
}
```

**Verification**: Both files compile. Tapping a category card in the Vitamin Shelf pushes `CategoryGoalListView` with the correct title. Goals filtered correctly — only non-completed goals in the selected category appear.
