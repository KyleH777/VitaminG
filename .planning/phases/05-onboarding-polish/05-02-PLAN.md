```swift
ForEach(GoalTier.ordered, id: \.self) { tier in
```

**Replace with:**
```swift
ForEach(GoalTier.ordered, id: \.self) { tier in
    let tieredGoals = goals(for: tier)
    TierSectionView(tier: tier) {
        if tieredGoals.isEmpty {
            EmptyTierView(tier: tier) {
                viewModel.draftTier = tier
                showingAddGoal = true
            }
        } else {
            ForEach(tieredGoals) { goal in
                goalRow(for: goal)
            }
        }
    }
}
```

Key changes:
1. Remove the `if !tieredGoals.isEmpty` guard so that ALL tier sections render even when empty
2. Inside `TierSectionView`, branch on `tieredGoals.isEmpty` to show `EmptyTierView` or goal rows
3. The `EmptyTierView` onAdd closure sets `viewModel.draftTier = tier` BEFORE setting `showingAddGoal = true` — this pre-selects the tier in AddGoalView (per D-06: "opens AddGoalView pre-set to that tier")

**Important:** This change ONLY applies to the `else` branch of `if sortOption == .byCompletionStatus` (lines 107-119). Do NOT modify the `.byCompletionStatus` branch (lines 89-106). Per-tier empty states only appear in byTier sort mode (per RESEARCH.md Pitfall 3).
