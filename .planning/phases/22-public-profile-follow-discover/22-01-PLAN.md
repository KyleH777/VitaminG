## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client → CloudKit public DB | Every new field (motto, streakLength, goalCount on PublicProfile; PublicGoal record contents; Follow record contents) is user-controlled input crossing into a publicly readable database |
| SwiftData migration | V8 → V9 lightweight migration runs on every user's device; failure here corrupts existing data |
| CloudKit Console schema | Manual deployment step — wrong field types or missing indexes silently break Discover search |
