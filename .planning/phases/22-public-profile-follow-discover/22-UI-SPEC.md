# Phase 22 — UI Design Contract
## Public Profile + Follow + Discover

> Visual and interaction contract for Phase 22 frontend implementation.
> Generated by gsd-ui-researcher. Source of truth for gsd-planner, gsd-executor, and gsd-ui-auditor.

## Design System

| Property | Value |
|----------|-------|
| Tool | VGTheme.swift (custom Swift enum, already implemented) |
| Preset | not applicable — native SwiftUI, no shadcn or web registry |
| Component library | Native SwiftUI + existing VG shared components |
| Icon library | SF Symbols (system images via `systemName:`) |
| Heading font | CormorantGaramond via `VGTheme.serif(size)` |

## Spacing Scale

All values in points (iOS pt, not CSS px). Multiples of 4pt enforced.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4pt | Icon-to-label gaps, inline chip padding |
| sm | 8pt | Compact element spacing, avatar-to-text gaps |
| md | 16pt | Card horizontal padding, default element spacing |
| lg | 24pt | Section vertical padding, profile header top margin |
| xl | 32pt | Major layout gaps |
| 2xl | 48pt | Hero section bottom padding |
| 3xl | 64pt | Page-level vertical padding (rare) |

**Exceptions:**
- Minimum touch target: 44×44pt (HIG requirement) — applied to FollowButton, CheerButton, all icon-only buttons
- Progress ring sizes: 32pt (GoalSearchResultCard), 44pt (PublicGoalCard on profile), 28pt (GoalRowView, unchanged)
- Avatar on PublicProfileView: 80pt (up from 72pt in current implementation)

## Typography

All iOS pt sizes. Two weights maximum per the design system.

| Role | Size | Weight | Font | Line Height | Usage |
|------|------|--------|------|-------------|-------|
| Display | 28pt | Regular (400) | `VGTheme.serif(28)` | 1.2 | PublicProfileView section heading "Jordan Kim" display name |
| Heading | 20pt | Semibold (600) | `.system(size:20, weight:.semibold).fontDesign(.rounded)` | 1.25 | Section labels (uppercased + 0.4 kerning), card titles |
| Body | 16pt | Regular (400) | `.system(size:16).fontDesign(.rounded)` | 1.5 | Motto/bio text, goal descriptions in cards |
| Label | 13pt | Semibold (600) | `.system(size:13, weight:.semibold).fontDesign(.rounded)` | 1.3 | Stat values, follower counts, category tags, section eyebrow labels |
| Caption | 12pt | Regular (400) | `.system(size:12).fontDesign(.rounded)` | 1.4 | Username prefix in cards (`@username`), timestamp hints, "Shared via Vitamin G" footer |

**Typography rules:**
- Section eyebrow labels (e.g., "MY PUBLIC GOALS", "DISCOVER"): 13pt semibold, `.kerning(0.4)`, `.textCase(.uppercase)`, `VGTheme.textMuted` color
- Stat figures (streak count, goal count, cheers given): 20pt semibold serif (`VGTheme.serif(20, weight: .semibold)`)
- Stat labels beneath figures: 12pt regular SF Rounded, `VGTheme.textMuted`
- Search placeholder text: system default `.searchable` modifier — do not override font
- Empty state heading: 16pt semibold SF Rounded
- Empty state body: 14pt regular SF Rounded, `VGTheme.textSecondary`

## Color

60/30/10 distribution applied to each screen surface.

| Role | VGTheme Token | Raw Value (light / dark) | Usage |
|------|---------------|--------------------------|-------|
| Dominant (60%) | `VGTheme.background` | `#FAF5EE` / `#16110C` | Page background for PublicProfileView and DiscoverView |
| Secondary (30%) | `VGTheme.surface` | `#FDFAF6` / frosted warm | Card backgrounds — PublicGoalCard, GoalSearchResultCard, PeopleSearchResultCard, stat cells |
| Surface variant | `VGTheme.surface2` | sandMid 40% / frosted 7% | Avatar background fallback, inactive ring track |
| Accent — Terra (10%) | `VGTheme.accentTerra` | `#C4673A` / `#FF8A5C` | FollowButton (active state), Join button, progress ring arc, "Done" nav button |
| Accent — Sage | `VGTheme.accentSage` | `#7A9E7E` / `#95D69C` | FollowButton AFTER follow confirmed ("Following" state), success confirmation tint |
| Accent — Gold | `VGTheme.accentGold` | `#C4A459` / `#E8D070` | CheerButton icon, floating applause animation overlay, cheers given stat |
| Separator | `VGTheme.separator` | `#E8D9C4` / 7% warm | Dividers between profile sections |
| Text primary | `VGTheme.textPrimary` | clay / sand | Display names, goal titles |
| Text secondary | `VGTheme.textSecondary` | clay 75% / sand 62% | Category tags, participant counts, bio text |
| Text muted | `VGTheme.textMuted` | `#9A8A78` / sand 42% | Section eyebrow labels, username captions, timestamp hints |
| Destructive | `Color.red` (system) | — | "Block User" button label and alert action |

**Accent reserved for (explicit list — no other uses):**
1. FollowButton background (pre-follow)
2. Join button background (Discover results)
3. Progress ring arc fill on PublicGoalCard and GoalSearchResultCard
4. "Done" navigation bar button (inherited pattern)
5. CheerButton icon (gold, not terra — see above)

**Color rules:**
- CheerButton uses `VGTheme.accentGold`, NOT `VGTheme.accentTerra` — it is an applause action, not a navigation CTA
- FollowButton transitions from terra → sage on follow confirmation to signal completion, not ongoing action
- Disabled CheerButton: `.opacity(0.35)` on the button, no color swap — gold tint preserved but visually suppressed
- Card corner radius: 16pt — `RoundedRectangle(cornerRadius: 16)`
- Card shadow (light mode only): `shadow(color: .black.opacity(0.04), radius: 6, y: 2)`

Toggleable follow button with three states: idle, loading, and followed.

| State | Appearance |
|-------|-----------|
| Idle (not following) | Background `VGTheme.accentTerra`, foreground `.white`, label "Follow" |
| Loading | Background `VGTheme.accentTerra.opacity(0.7)`, inline `ProgressView` (white tint), disabled |
| Followed | Background `VGTheme.accentSage`, foreground `.white`, label "Following" |

| Property | Value |
|----------|-------|
| Corner radius | 20pt (pill shape) |
| Horizontal padding | 20pt |
| Vertical padding | 10pt |
| Font | 15pt semibold SF Rounded |
| Minimum touch target | 44×44pt |

### DiscoverView

New view replacing/extending the ExploreView search capability. Lives inside the Explore tab (or as a dedicated tab section — implementation detail for planner to decide; this spec covers the visual contract).

**Layout (top to bottom):**

```
NavigationStack
  .navigationTitle("Discover")
  .navigationBarTitleDisplayMode(.large)

VStack
  ├── .searchable modifier — search bar pinned to top
  │     placeholder: "Search goals or people…"
  │     debounced 500ms (DISC-01)
  │
  ├── Segment control (shown when search is active, hidden when empty)
  │     Picker("", selection: $segment) — .segmented style
  │       "Goals"  |  "People"
  │     padding H: 16, V: 8
  │
  ├── [When searchText is empty]
  │     ScrollView (VGTheme.background)
  │       Section label: "TRENDING CHALLENGES"
  │       TrendingChallengesSection (§6 spec)
  │
  └── [When searchText is non-empty]
        ScrollView (VGTheme.background)
          [Goals segment]
            LazyVStack(spacing: 8) { GoalSearchResultCard × N }
            — or empty state —
          [People segment]
            LazyVStack(spacing: 8) { PeopleSearchResultCard × N }
            — or empty state —
```

**Search debounce:** 500ms — implemented in DiscoverViewModel using `Task.sleep` or Combine `debounce`. Results update after 500ms of no additional input. Loading indicator: `ProgressView()` inline at top of results list, `.tint(VGTheme.accentTerra)`.

**Segment transition:** `.animation(.easeInOut(duration: 0.2), value: selectedSegment)` — list content crossfades on segment switch.

**Reduced motion:** Skip list crossfade animation; swap content immediately.

## Interaction Specifications

### CheerButton Animation

1. User taps CheerButton when `canCheerToday == true`
2. `onApplaud()` closure fires — backend write begins async
3. Animation plays (unless `accessibilityReduceMotion`):
   - `ZStack` overlay: "👏" + giverUsername VStack
   - Initial state: `floatOffset = 0`, `floatOpacity = 1.0`
   - `withAnimation(.easeOut(duration: 1.0))`: `floatOffset = -80`, `floatOpacity = 0`
   - After 1.1s: overlay hidden
4. Button transitions to used state: label → "Cheered today", opacity → 0.35
5. `canCheerToday` stored in ViewModel (persisted as Date in UserDefaults, same pattern as `vg_explore_gifterDate`)

### FollowButton State Machine

```
.idle ──tap──> .loading (disable button, show inline ProgressView)
    .loading ──CloudKit write success──> .followed (background: accentSage, label: "Following")
    .loading ──CloudKit write failure──> .idle (re-enable button, show error banner below button)
```

- Spring animation on color/label transition: `.spring(response: 0.35, dampingFraction: 0.75)`
- Error banner: inline `Text("Couldn't follow right now. Tap to retry.")` at 13pt, `VGTheme.accentTerra`, fades in below button
- Error banner auto-hides after 3 seconds

### Search Debounce UX

1. User types in search field
2. DiscoverViewModel resets debounce timer on each keystroke
3. After 500ms of no input: search fires
4. While search in flight: show `ProgressView` at top of results area
5. Results arrive: replace ProgressView with result cards
6. On empty results: replace ProgressView with empty state
7. On error: replace ProgressView with error state
8. Clearing search field: dismiss results, show TrendingChallengesSection

### Progress Ring Animation

PublicGoalCard progress ring uses the same animation as `ProgressRingView`:
```swift
.animation(
    reduceMotion ? nil : .easeInOut(duration: 0.4),
    value: progress
)
```
Rings animate in when the card appears. Use `.onAppear` to trigger progress from 0 → actual value for entry animation. Skip entry animation when `accessibilityReduceMotion` is true.

### Join Button Interaction

1. User taps "Join" on GoalSearchResultCard
2. Button immediately transitions to "Joined" + disabled (optimistic update)
3. Backend: add goal to local SwiftData + increment participant count in CloudKit
4. On failure: revert button to "Join" state, show inline error

### Pull-to-Refresh

Both PublicProfileView and DiscoverView support `.refreshable` — re-fetches profile data or re-runs search query respectively.
