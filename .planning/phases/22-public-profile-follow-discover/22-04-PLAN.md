## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| App launch → CloudKit | Fire-and-forget Tasks run before the user interacts with any UI; failures must not surface as errors |
| GoalViewModel.addCheckIn → CloudKit | New writes piggyback on the user's check-in action; failures must not interrupt the check-in success path |
| ProfileEditSheet → SwiftData → CloudKit | User-typed motto crosses the trust boundary into the public DB; sanitization at service layer is mandatory |
