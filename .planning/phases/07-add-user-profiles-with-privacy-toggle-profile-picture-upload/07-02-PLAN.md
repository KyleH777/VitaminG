<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User input -> displayName | Untrusted string; must sanitize and length-cap before SwiftData persist |
| SwiftData @Query -> View | Public goals list rendered from @Query; must handle empty gracefully |
| isPublic toggle -> CloudKit (Plan 03) | Toggle sets local state immediately; CloudKit write is async and can fail |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-04 | Tampering | ProfileViewModel.validateAndSaveDisplayName | mitigate | Strip control characters, normalize whitespace, enforce 50-char max before SwiftData insert — same sanitize() pattern as GoalViewModel |
| T-07-05 | Information Disclosure | PublicGoalsSection | accept | Only goal titles and tier displayed in public goals list — no descriptions, no inspiration text, no completion data. Acceptable exposure since user explicitly marked goals public. |
| T-07-06 | Denial of Service | loadOrCreateProfile | mitigate | fetchLimit = 1 on FetchDescriptor prevents unbounded query; singleton creation guarded by fetch-first pattern |
| T-07-07 | Spoofing | displayName input | mitigate | HTML/script tags stripped by sanitize() control character removal; no web rendering surface exists |
</threat_model>
