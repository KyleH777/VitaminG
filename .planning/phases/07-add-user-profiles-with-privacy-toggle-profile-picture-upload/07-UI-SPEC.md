## Spacing Scale

All values in points. Must be multiples of 4. Matches spacing already used in GoalDetailView, StatsView, GoalListView.

| Token | Value (pt) | SwiftUI Usage |
|-------|-----------|---------------|
| xs | 4 | Icon gaps, inline symbol padding |
| sm | 8 | Compact element spacing (VStack/HStack gaps) |
| md | 16 | Default section padding, card padding |
| lg | 24 | Between major card sections |
| xl | 32 | Bottom safe-area padding, page-level spacing |
| 2xl | 48 | Avatar to content gap (profile header) |
| 3xl | 64 | Unused in this phase |

Exceptions:
- Avatar circle diameter: 88pt (not a gap token — frame size)
- Minimum tappable touch target for any interactive element: 44pt (matches existing GoalRowView button frame)
- Privacy toggle tap target height: 44pt minimum

Source: Existing codebase (GoalDetailView spacing: 8/16/32, StatsView: 16/20, GoalListView: 4/14).

## Typography

All fonts use `.system(design: .rounded)`. No other font family is used in this app.

| Role | Size | Weight | Line Height | SwiftUI Expression | Usage |
|------|------|--------|-------------|-------------------|-------|
| Caption | 12pt | `.regular` | 1.4 | `.system(size: 12, weight: .regular, design: .rounded)` | Metadata labels, dates, secondary notes |
| Label | 13pt | `.semibold` | 1.3 | `.system(size: 13, weight: .semibold, design: .rounded)` | Section headers, "Notes" label, "Public Goals" section header |
| Body | 16pt | `.regular` / `.semibold` | 1.5 | `.system(size: 16, weight: .regular, design: .rounded)` | Display name, goal titles in public preview list |
| Subhead | 18pt | `.semibold` | 1.3 | `.system(size: 18, weight: .semibold, design: .rounded)` | Privacy toggle label, Share Profile button label |
| Title | 22pt | `.semibold` | 1.2 | `.system(size: 22, weight: .semibold, design: .rounded)` | Display name (primary, centered in profile header) |
| Avatar Initials | 34pt | `.semibold` | 1.0 | `.system(size: 34, weight: .semibold, design: .rounded)` | Initials rendered inside the 88pt avatar circle |

Weights permitted in this phase: `.regular` (400) and `.semibold` (600).
`.medium` and `.bold` must not be introduced in new views — maintain existing app weight range.

Source: Codebase audit — GoalDetailView uses 12/16/22pt, GoalListView uses 16pt body, AddGoalView uses form patterns. Avatar initials size derived from 88pt circle with standard 38% text ratio.

## Component Inventory

SwiftUI views introduced or modified in this phase.

### New Views

#### `ProfileView` (new file)

```
NavigationStack
  ScrollView
    VStack(spacing: 24)
      [1] AvatarView                    — 88pt circle, initials
      [2] DisplayNameRow                — name + edit pencil button
      [3] PrivacyToggleRow              — "Profile Visibility" segmented/toggle
      [4] PublicGoalsSection            — List of isPublic goals, or empty state
      [5] ShareProfileButton            — disabled when isPublic == false
```

Layout: `VStack(spacing: 24)` inside `ScrollView`, `.padding(.horizontal, 16)`, `.padding(.top, 32)`.
Background: `Color(UIColor.systemGroupedBackground)` — matches StatsView.

#### `AvatarView` (subview of ProfileView)

- Frame: 88 × 88pt circle (`Circle().frame(width: 88, height: 88)`)
- Fill: assigned avatar color slot (`avatarColor`)
- Text: up to 2 characters from initials, 34pt semibold rounded, `Color.white`
- Shadow: `.shadow(color: .black.opacity(0.10), radius: 8, y: 4)`
- Accessibility: `.accessibilityLabel("Profile avatar for \(displayName)")`
- No tap gesture in Phase 7 (photo upload deferred)

#### `DisplayNameRow` (inline in ProfileView)

- Layout: `HStack` — display name text left, edit pencil button right
- Display name: 22pt semibold rounded, `Color.primary`
- Subtext below name: character count hint only when editing (same `CharacterCountView` pattern from AddGoalView)
- Edit mode: tapping pencil presents `ProfileEditSheet` (`.sheet` presentation)
- Accessibility: `.accessibilityLabel("Display name: \(displayName). Double-tap to edit.")`

#### `ProfileEditSheet` (sheet, new file or subview)

- Presentation: `.sheet` (matches AddGoalView pattern)
- Content: `NavigationStack` > `Form` with one `Section` containing a `TextField`
- TextField placeholder: "Your name"
- Max chars: 50 (enforced via `.onChange` — same CharacterCountView pattern)
- Toolbar: "Cancel" (cancellationAction) + "Save" (confirmationAction, `.semibold`, disabled when empty)
- Validation: display name cannot be blank. Error: inline `.alert` with message "Name cannot be empty."

#### `PrivacyToggleRow` (inline in ProfileView, inside a card)

- Visual treatment: iOS `Toggle` — NOT a segmented control
- Label: "Public Profile"
- Sublabel (below toggle row, in Section footer): "When public, anyone with your share link can view your goals that you've marked as public."
- Toggle `isOn` binding: `ProfileViewModel.isPublic`
- Container: `Form` `Section` with header "Profile Visibility"
- When toggled ON → ProfileViewModel writes `isPublic = true` to SwiftData, triggers CloudKit public database write
- When toggled OFF → Share Profile button disables immediately (no confirmation needed for turning private)
- Accessibility: `.accessibilityLabel("Public profile. \(isPublic ? "On" : "Off"). Double-tap to toggle.")`

#### `PublicGoalsSection` (inline in ProfileView)

- Header: "Public Goals" (13pt semibold, `.secondary`)
- Content: `LazyVStack` of `PublicGoalRow` views, one per `isPublic == true` goal
- Empty state (when no public goals): see Copywriting Contract below
- `PublicGoalRow`: HStack — tier color pip (4×36pt, cornerRadius 3) + goal title (16pt regular rounded) + tier icon SF Symbol (12pt, tier.color)
- Matches existing GoalRowView visual language (pip size/style from GoalListView)
- No navigation from these rows in Phase 7 (read-only preview)

#### `ShareProfileButton` (inline in ProfileView, below PublicGoalsSection)

- Style: `.buttonStyle(.borderedProminent)` with `.tint` set to accent gradient via overlay
- Exact implementation:
  ```swift
  Button("Share Profile") { ... }
    .buttonStyle(.borderedProminent)
    .tint(Color(red: 0.98, green: 0.55, blue: 0.27))  // fallback tint; gradient via label overlay
    .disabled(!viewModel.isPublic)
    .frame(maxWidth: .infinity)
    .padding(.vertical, 4)
  ```
- When disabled: system disabled appearance (opacity 0.5, non-interactive)
- When tapped: presents system share sheet (`ShareLink` or `UIActivityViewController`) with deep link URL
- Share sheet pre-populated text: "Check out my goals on Vitamin G!" + deep link URL
- SF Symbol prefix: `square.and.arrow.up`
- Accessibility: when disabled, `.accessibilityHint("Set your profile to public to enable sharing")`

#### `GoalDetailView` modification — Public Toggle

Added to existing `GoalDetailView` as a new section between the header section and quote card:

- Container: `GroupBox` or standalone `HStack` card (white background, 12pt corner radius, 16pt padding — matches existing headerSection style)
- Label: "Share this goal" (16pt regular rounded)
- Control: `Toggle("", isOn: $goalViewModel.isPublicDraft)` — no label text, label provided by enclosing HStack
- Subtext below: "Public goals appear on your profile when your profile is set to public." (12pt regular, `.secondary`)
- Changes saved immediately via `viewModel.updateGoalPublicStatus(goal:isPublic:context:)` — no separate Save tap required
- Accessibility: `.accessibilityLabel("Share this goal. \(goal.isPublic ? "On" : "Off")")`

## Interaction Contracts

### Avatar Color Assignment

- On first ProfileView visit (no UserProfile exists): `ProfileViewModel.createProfile()` selects one of 6 avatar colors using `Int.random(in: 0..<6)`, persists the index (or hex string) to `UserProfile.avatarColorHex`
- Color is loaded from `avatarColorHex` on every subsequent visit — never re-randomized
- Initials derived from `displayName`: split by whitespace, take first character of each word, uppercase, max 2 characters. If `displayName` is nil or empty, show a single "?" character at 34pt

### Privacy Toggle Interaction

- Toggle flip to Public: `ProfileViewModel` sets `isPublic = true` in SwiftData immediately. CloudKit public database write is attempted in background. If CloudKit write fails: show `.alert` "Couldn't share your profile. Check your internet connection and try again." Toggle remains ON (optimistic UI — will sync when connectivity restores via CloudKit automatic retry).
- Toggle flip to Private: `ProfileViewModel` sets `isPublic = false` immediately. Share button disables. No confirmation dialog required (low-stakes reversal).
- Share button disabled state transitions: animate with `.animation(.easeInOut(duration: 0.2), value: isPublic)`

### Display Name Edit

- Pencil button taps → sheet presents with current name pre-filled
- Save: validates non-empty, trims whitespace, persists to SwiftData
- Cancel: dismisses without saving
- Character limit enforced live: same CharacterCountView pattern at 50 chars

### Public Goal Toggle (GoalDetailView)

- Toggle flip: immediate write to SwiftData via ViewModel
- No confirmation dialog
- If profile is Private, toggling a goal Public is permitted (goals are "staged" as public; they become visible only when the profile itself is made public)
- Accessibility state announcement: use `.accessibilityValue(isPublic ? "On" : "Off")`

### Empty State Transitions

- When user has no public goals: show empty state card (see Copywriting). Transition to list: `.animation(.easeOut(duration: 0.25), value: publicGoals.count)` — matches existing GoalListView animation duration

## States and Visual Modes

### ProfileView States

| State | Visual |
|-------|--------|
| First visit / no profile | Profile created silently; avatar color assigned; name empty; prompt to add name via pencil edit |
| Profile Private | Toggle off, Share button disabled (0.5 opacity), Public Goals section shows empty state if no public goals |
| Profile Public, no public goals | Toggle on, Share button enabled, Public Goals section shows empty state copy |
| Profile Public, has public goals | Toggle on, Share button enabled, Public Goals list populated |
| CloudKit write pending | No blocking UI — optimistic update; background retry handled by CloudKit |
| CloudKit write failed | Alert presented once; does not revert toggle |

### Light / Dark Mode

All colors use semantic SwiftUI values where possible:
- `Color.primary`, `Color.secondary`, `Color(.secondarySystemGroupedBackground)`, `Color(UIColor.systemGroupedBackground)` — automatic dark mode adaptation
- Avatar colors (hardcoded RGB) are sufficiently saturated to read well in dark mode
- Card backgrounds: use `Color.white` in light mode; for dark mode compatibility, prefer `Color(.systemBackground)` in new ProfileView cards rather than `Color.white`

New views must use `Color(.systemBackground)` for card surfaces (not `Color.white`) to ensure dark mode correctness. This is a refinement over the existing pattern (GoalDetailView uses `Color.white` which is a known minor issue).

## Accessibility Contract

All interactive elements must meet iOS accessibility standards (REQUIREMENTS.md UI-06):

| Element | Requirement |
|---------|-------------|
| Avatar circle | `.accessibilityLabel("Profile avatar for \(displayName)")` — static text trait |
| Display name + edit button | `.accessibilityElement(children: .combine)` or separate labels |
| Privacy toggle | `.accessibilityLabel("Public profile")` + `.accessibilityValue(isPublic ? "On" : "Off")` |
| Share Profile button (enabled) | Default button label sufficient |
| Share Profile button (disabled) | `.accessibilityHint("Set your profile to public to enable sharing")` |
| Goal public toggle | `.accessibilityLabel("Share this goal")` + `.accessibilityValue(isPublic ? "On" : "Off")` |
| Public goal rows | `.accessibilityLabel("\(goal.title ?? "Goal"), \(goal.tier.displayName) tier")` |
| Character count views | `.accessibilityLabel("\(current) of \(max) characters used")` |

Dynamic Type: all font declarations use `.system(size:weight:design:)` — these do NOT scale with Dynamic Type. For Phase 7, this matches the existing app pattern (no `Font.body` / `Font.title` semantic sizes used anywhere in existing views). This is an existing limitation, not introduced by Phase 7.
