| Property | Value |

## Spacing Scale

All values in SwiftUI points (1pt = 1px on non-Retina; design-side measure). Must be multiples of 4.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4pt | `spacing: 4` — internal VStack row gaps (e.g. ring-to-text gap) |
| sm | 8pt | `spacing: 8` — section header-to-content gaps in GoalDetailView |
| md | 16pt | `padding(16)` — card horizontal and vertical padding (matches existing cards) |
| lg | 24pt | `spacing: 24` — VStack spacing between major sections in GoalDetailView |
| xl | 32pt | `.padding(.bottom, 32)` — bottom scroll inset on GoalDetailView |
| 2xl | 48pt | not used in this phase |
| 3xl | 64pt | not used in this phase |

Exceptions:
- Progress ring diameter: **28pt** (not a spacing multiple; it is a fixed component dimension from D-01)
- Progress ring stroke width: **3pt** (component dimension from D-01)
- Chart height: **80pt** (component dimension from D-10; matches compact GoalDetailView constraint)
- Completion toggle touch target: **44pt** min width/height (pre-existing; unchanged)
- Tier pip slot (now ring slot): same HStack slot as existing 4×36pt pip — ring occupies 28pt diameter within that slot

## Typography

All typography uses `.fontDesign(.rounded)` per project convention. Sizes below are SwiftUI text styles (Dynamic Type-scaled), not fixed px — the project requires Dynamic Type support (UI-06).

| Role | SwiftUI Style | Weight | Line Height |
|------|--------------|--------|-------------|
| Body | `.body` | tier-driven (`typographicWeight`) or `.regular` | system default (~1.5) |
| Label / Caption | `.caption` | `.regular` | system default |
| Footnote label | `.footnote` | `.semibold` | system default |
| Section heading (chart) | `.subheadline` | `.semibold` | system default (~1.2) |

**Phase-specific typography notes:**

- **Progress section label** ("Total completions", "Last completed", "Momentum"): `.body.fontDesign(.rounded)` — weight `.regular`, same as existing GoalDetailView body rows.
- **Momentum score value** (e.g. "0.57"): `.body.fontDesign(.rounded)` — weight `.semibold` to distinguish from label.
- **Momentum subtitle** ("completions in the last 7 days"): `.caption.fontDesign(.rounded)` — weight `.regular`, `.secondary` color.
- **Chart section header** ("Progress History"): `.footnote.weight(.semibold).fontDesign(.rounded)` — matches "Notes" section header in existing GoalDetailView.
- **Chart axis labels** (abbreviated day labels): `.caption2` — system default, no manual override.
- **Summary row values** ("N" in "Total completions: N", date in "Last completed: date"): `.body.weight(.semibold).fontDesign(.rounded)`.

## Component Inventory

### 1. ProgressRingView (new component)

**Location:** New file `VitaminG/Views/ProgressRingView.swift`

**Geometry:**
- Outer diameter: 28pt
- Stroke width: 3pt (applied with `.strokeStyle(.init(lineWidth: 3, lineCap: .round))`)
- Background circle: same diameter, `tier.color.opacity(0.15)`, no stroke
- Progress arc: `Circle().trim(from: 0, to: progress)`, clockwise from 12 o'clock (rotated `-90°`)

**States:**

| State | Appearance |
|-------|-----------|
| Empty (progress = 0) | Background circle only at `opacity: 0.15`; no arc visible |
| Partial (0 < progress < 1) | Arc at tier color, full opacity |
| Full — active goal (progress = 1) | Full arc at tier color |
| Full — completed goal | Full arc at `completionGreen` (#10B981) |

**Animation:**
- Default: `.animation(.easeInOut(duration: 0.4), value: progress)` on appear and value change
- Reduced motion (`@Environment(\.accessibilityReduceMotion) == true`): skip animation; render static fill instantly

**VoiceOver:**
- Label: `"\(Int(progress * 100))% momentum this week"` for active goals
- Label: `"Goal complete"` for completed goals
- Trait: `.isStaticText`

---

### 2. Progress ring in GoalRowView (modified)

**Change:** Replace existing tier pip (`RoundedRectangle` 4×36pt) at the trailing end of the HStack with `ProgressRingView`.

**Layout contract:**
- Same HStack trailing slot
- `ProgressRingView(progress: ringProgress, tier: goal.tier, isCompleted: goal.completed)`
- `ringProgress` = `ProgressViewModel.ringProgress(for: goal, events: goalEvents)` — computed in GoalListView, passed as `Double`
- No additional padding change; the 28pt circle fits within the 36pt height of the former pip

---

### 3. Progress History Section in GoalDetailView (new section)

**Placement:** New `progressSection` inserted below `quoteCardSection` and above `notesSection`.

**Card style:** Matches existing card pattern — `.background(Color(.systemBackground))`, `.clipShape(RoundedRectangle(cornerRadius: 12))`, `.padding(.horizontal)`.

**Internal layout (top to bottom):**

```
[Section header: "Progress History" — .footnote.semibold.secondary]
[Gap: 8pt]
[Summary row: "Total completions"   [N — semibold]]
[Summary row: "Last completed"      [date string or "Never" — semibold]]
[Gap: 12pt]
[Swift Charts BarChart — 80pt height]
[Gap: 12pt]
[Momentum row]
```

**Summary rows:** `HStack` with `Text(label)` leading + `Spacer()` + `Text(value)` trailing. Both at `.body.fontDesign(.rounded)`, label at `.regular`, value at `.semibold`.

**"Last completed" date format:** `date.formatted(date: .abbreviated, time: .omitted)` — consistent with existing GoalDetailView date displays.

---

### 4. Swift Charts Bar Chart (within Progress History Section)

**Framework:** `import Charts` (Apple, iOS 16+, no third-party)

**Data model:** `[DayCount]` — struct with `date: Date` and `count: Int`. Provided by `ProgressViewModel.chartData(for:events:)`. 30 items covering today back 29 days.

**Chart spec:**
- `Chart(data) { BarMark(x: .value("Day", item.date), y: .value("Count", item.count)) }`
- Bar color: `tier.color` via `.foregroundStyle(goal.tier.color)`
- X-axis: shows abbreviated day label only for the last 7 days; older bars show no label (use `AxisMarks` with conditional visibility)
- Y-axis: hidden (`.chartYAxis(.hidden)`) — count readable from bar height; chart is ambient/indicative not precise
- Chart height: `.frame(height: 80)`
- Days with 0 completions: `BarMark` with count 0 renders as a 0-height bar — the full 30-day x-axis is always present (shows the span visually)
- No chart legend
- No chart title (section header "Progress History" serves this purpose)

**Accessibility:**
- `.accessibilityLabel("30-day completion history bar chart")`
- `.accessibilityValue("\(totalCompletions) completions in the last 30 days")`

**Reduced motion:** Chart renders statically with no appear animation. No `chartAnimation` modifier.

---

### 5. Momentum Row (within Progress History Section)

**Layout:** `HStack(spacing: 8)` with:
1. Color dot: `Circle().fill(momentumColor).frame(width: 10, height: 10)`
2. `VStack(alignment: .leading, spacing: 2)`:
   - `Text("Momentum")` — `.body.fontDesign(.rounded)` weight `.regular`
   - `Text("completions in the last 7 days")` — `.caption.fontDesign(.rounded)` weight `.regular` `.secondary`
3. `Spacer()`
4. `Text(momentumValueString)` — e.g. "0.57" formatted as `String(format: "%.2f", score)` — `.body.weight(.semibold).fontDesign(.rounded)`

**Color dot values:**

| Condition | Color |
|-----------|-------|
| score ≥ 0.5 | `Color.green` |
| 0.1 ≤ score < 0.5 | `Color.orange` |
| score < 0.1 | `Color.secondary` |

**VoiceOver:**
- `.accessibilityElement(children: .combine)`
- `.accessibilityLabel("Momentum score \(momentumValueString). \(momentumAccessibilityDescription). Based on completions in the last 7 days.")`
- Where `momentumAccessibilityDescription` = "High" / "Medium" / "Inactive"

---

### 6. Milestone Celebration Badge Overlay (new interaction)

**Trigger:** After `GoalViewModel.toggleCompletion` increments `completionEvents.count` to exactly 5, 10, 25, or 50.

**Visual:**
- SF Symbol: `.star.fill` (tiers immediate/shortTerm/longTerm); `.trophy.fill` for the 50-completion milestone
- Color: `goal.tier.color`
- Size: `.font(.system(size: 48))`
- Placement: centered overlay on the GoalRowView card (`.overlay` in `GoalRowView`)

**Animation sequence (default motion):**

| Step | Duration | Transform |
|------|----------|-----------|
| Appear | 0.2s, `.easeOut` | scale 0.5 → 1.2, opacity 0 → 1 |
| Settle | 0.15s, `.spring(response: 0.3, dampingFraction: 0.6)` | scale 1.2 → 1.0 |
| Hold | 1.5s | static |
| Fade out | 0.3s, `.easeIn` | opacity 1 → 0 |

**Reduced motion animation:**

| Step | Duration | Transform |
|------|----------|-----------|
| Appear | instant | scale 1.0, opacity 1 |
| Hold | 0.5s | static |
| Fade out | 0.2s, `.easeIn` | opacity 1 → 0 |

**Non-blocking:** The badge is a pure overlay (`.overlay(alignment: .center)`) — no modal, no sheet, no navigation interruption. The goal list remains fully interactive.

**Session deduplication:** `Set<String>` keyed by `"\(goalID.uuidString)-\(threshold)"` stored on `GoalViewModel`. Within one app session, each threshold per goal fires at most once. Re-fires on app relaunch (acceptable per D-13).

**VoiceOver announcement:** Use `UIAccessibility.post(notification: .announcement, argument: "Milestone reached: \(threshold) completions!")` after the animation begins.

## Interaction States

### Progress Ring — GoalRowView

| State | Trigger | Visual |
|-------|---------|--------|
| Default render | View appears | Static ring at computed progress |
| Completion toggled | User taps completion toggle | Ring animates from old progress to new value (`.easeInOut(duration: 0.4)`) |
| Goal marked complete | `isCompleted == true` | Ring snaps to 1.0 in `completionGreen` |
| Reduced motion | System preference | No animation; static render at correct value |

### Milestone Badge — GoalRowView

| State | Trigger | Visual |
|-------|---------|--------|
| Inactive | No threshold crossed | No overlay rendered |
| Celebrating | Threshold just crossed | Badge animates in, holds, fades out |
| Suppressed (already fired this session) | Same threshold, same goal | No overlay |

### Chart — GoalDetailView

| State | Trigger | Visual |
|-------|---------|--------|
| No history | 0 completions in 30 days | All bars at height 0; x-axis and grid still visible |
| Has history | ≥1 completion in range | Bars at tier color, varying heights |
