## Scope

Phase 4 adds three UI surfaces:
1. **Home screen widget** (`systemMedium`) — `GoalSummaryWidget`: 4 tier rows + optional streak footer
2. **Lock screen widget** (`accessoryRectangular`) — `StreakWidget`: streak count or top Immediate goal title
3. **Settings streak row** — Motivational global streak display added to `SettingsView`

No interactive elements in this phase. All widget surfaces are read-only (`StaticConfiguration`).

## Spacing Scale

SwiftUI padding values — all multiples of 4.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4pt | Icon-to-text gaps within a row |
| sm | 8pt | Spacing between icon and label in tier headers |
| md | 16pt | Default horizontal padding, inter-section gaps |
| lg | 20pt | VStack spacing in scroll content areas |
| xl | 24pt | Section separation in Forms |
| 2xl | 32pt | Horizontal padding for centered copy blocks |
| 3xl | 48pt | Not used in widget surfaces |

**Widget-specific spacing:**

| Context | Value | Rationale |
|---------|-------|-----------|
| Widget outer padding | 12pt (via `.containerBackground`) | WidgetKit renders `.containerBackground` padding automatically on iOS 17; do not add extra padding |
| Tier row internal padding | `.vertical` 6pt | Fits 4 rows + footer in systemMedium height without clipping |
| Icon-to-title gap in tier row | 8pt | Consistent with TierSectionView header in GoalListView |
| Footer divider top margin | 8pt | Visual separation from last tier row |

Exceptions: `.containerBackground(for: .widget)` is mandatory on all widget views (iOS 17 requirement per CLAUDE.md). Do not add `.padding()` outside `.containerBackground` — it causes double-margin artifacts.

Source: CLAUDE.md (`.containerBackground` note), codebase inspection of existing views

## Typography

All sizes in SwiftUI points (1pt = 1px on non-retina reference; system scales with Dynamic Type).

| Role | SwiftUI Style | Weight | Line Height | Usage |
|------|---------------|--------|-------------|-------|
| Widget tier title | `.subheadline` (15pt) | tier's `typographicWeight` | 1.2 | Goal title in each tier row of GoalSummaryWidget |
| Widget empty prompt | `.caption` (12pt) | `.regular` | 1.3 | "No [Tier] goals yet" in empty tier rows |
| Widget streak display | `.headline` (17pt) | `.bold` | 1.0 | Streak count number in footer and StreakWidget |
| Widget streak label | `.caption` (12pt) | `.regular` | 1.2 | "day streak" suffix, tier icon labels |
| Settings streak number | `.largeTitle` (34pt) | `.bold` | 1.0 | The prominent streak count in SettingsView (D-02) |
| Settings streak label | `.subheadline` (15pt) | `.regular` | 1.3 | "day streak" label below the number |

**Constraints:**
- Widget title text: `.lineLimit(1)` with `.truncationMode(.tail)` — widget surfaces cannot scroll
- Lock screen widget: `.lineLimit(2)` for goal title fallback (accessoryRectangular is ~2 lines tall)
- Settings streak number uses `.monospacedDigit()` modifier to prevent layout shift as number changes

Source: Established patterns in GoalListView.swift (16pt goal titles, `.caption` for descriptions), CONTEXT.md D-02 (streak "should be visually prominent, not a small subtitle")

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `Color(.widgetBackground)` / `.containerBackground` | Widget background (system-managed) |
| Secondary (30%) | Tier colors at `.opacity(0.12)` | Tier row background tint in GoalSummaryWidget |
| Accent (10%) | Full tier color + brand gradient | Reserved for: tier icon, tier name, tier color pip, streak flame icon, Settings streak count |

**Accent reserved for:**
- Tier icon (`Image(systemName: tier.icon)`) colored with `tier.color`
- Tier name label colored with `tier.color`
- Streak flame icon (`flame.fill`) colored with `Color(red: 0.98, green: 0.55, blue: 0.27)` (warm orange)
- Settings streak count number in brand gradient (orange → violet)
- Footer streak count in GoalSummaryWidget (warm orange `flame.fill` + number)

**Widget-specific color rules:**
- Use `.widgetBackground` (or `Color(.systemBackground)`) as the widget container background via `.containerBackground(for: .widget)` — not a hardcoded hex
- Widget vibrancy for lock screen: `accessoryRectangular` family must use `.widgetAccentable()` on the primary content so the system applies correct lock screen vibrancy automatically

Source: CLAUDE.md (`.containerBackground` required on iOS 17), Goal.swift (tier colors), StatsView.swift (streak gradient/flame pattern)

## Component Inventory

### 1. GoalSummaryWidget (systemMedium home screen)

```
GoalSummaryWidget
└── VStack(spacing: 6) [containerBackground]
    ├── ForEach GoalTier.ordered
    │   └── TierRowView (per tier)
    │       ├── HStack(spacing: 8)
    │       │   ├── Image(systemName: tier.icon) [tier.color, .caption weight]
    │       │   ├── Text(tier.displayName) [.caption, tier.color]
    │       │   └── Spacer()
    │       └── Text(topGoalTitle OR empty prompt) [.subheadline, tier.typographicWeight]
    └── Divider [conditional — omitted if streak == 0 AND using omit strategy]
    └── StreakFooterView [conditional — only when globalStreak > 0]
        └── HStack(spacing: 4)
            ├── Image("flame.fill") [warm orange, .caption]
            └── Text("\(streak) day streak") [.caption, .semibold]
```

**TierRowView visual spec:**
- Row background: `tier.color.opacity(0.10)` applied via `.background(RoundedRectangle(cornerRadius: 8))`
- Row padding: `.horizontal` 8pt, `.vertical` 6pt
- Icon size: `.caption` font (12pt) — keeps icon compact alongside title text
- Goal title: `.subheadline` at `tier.typographicWeight`, `.lineLimit(1)`, `.truncationMode(.tail)`
- Icon color: `tier.color` at full opacity

**Empty tier row spec:**
- Shows the tier icon + tier name row identically (visual consistency)
- Below, shows: `Text("No \(tier.displayName) goals yet").font(.caption).foregroundStyle(.secondary)`
- Row background same `tier.color.opacity(0.10)` — tier is still represented visually

**Footer spec (when globalStreak > 0):**
- `Divider()` above footer, top margin 8pt
- `HStack(spacing: 4)`: `Image(systemName: "flame.fill").foregroundStyle(Color(red: 0.98, green: 0.55, blue: 0.27))` + `Text("\(globalStreak) day streak").font(.caption).fontWeight(.semibold)`
- Footer omitted entirely when `globalStreak == 0` (D-04: "omitted or shows neutral encouragement" — use omit for widget cleanliness)

### 2. StreakWidget (accessoryRectangular lock screen)

Smart display per D-05:

**State A — streak > 0:**
```
VStack(alignment: .leading, spacing: 2)
├── HStack(spacing: 4)
│   ├── Image("flame.fill") [.widgetAccentable()]
│   └── Text("\(streak)") [.title2, .bold, .monospacedDigit()]
└── Text("day streak") [.caption, .secondary]
```

**State B — streak == 0:**
```
VStack(alignment: .leading, spacing: 2)
├── Text(topImmediateGoalTitle) [.subheadline, .semibold, .lineLimit(2)]
└── Text("Immediate goal") [.caption, .secondary]
```

- Both states use `.containerBackground(for: .widget)` at the top level
- `.widgetAccentable()` applied to the primary Text element so lock screen vibrancy renders correctly
- If no Immediate goals exist and streak is 0: show `Text("Set your first goal").font(.subheadline).foregroundStyle(.secondary)`

### 3. Settings Streak Row (SettingsView addition — D-02)

Added as a new `Section` above "Daily Reminder" in `SettingsView`:

```
Section {
    VStack(spacing: 8) {
        Text("\(globalStreak)")
            .font(.largeTitle.bold().monospacedDigit())
            .foregroundStyle(brand gradient — orange→violet)
        Text(globalStreak == 1 ? "day streak" : "days streak")
            .font(.subheadline)
            .foregroundStyle(.secondary)
    }
    .frame(maxWidth: .infinity)
    .padding(.vertical, 8)
}
```

- The streak number uses the brand gradient (LinearGradient, orange → violet) via a custom ViewModifier or directly with `.foregroundStyle(gradient)`
- No label prefix — the number speaks for itself (per CONTEXT.md: "dopamine hit — celebrate the number")
- Pluralization: "1 day streak" vs "N days streak"
- When streak is 0: section shows `Text("Start completing goals to build your streak").font(.subheadline).foregroundStyle(.secondary)` instead of the number

| Settings streak label | "day streak" / "days streak" (pluralized) |

**Copywriting rules for this phase:**
- Tone: warm and factual — never urgent or aggressive (UI-02 "not productivity-aggressive")
- Widget copy must be as short as possible — widget surfaces have extreme space constraints
- Goal titles are user-authored — always truncated to one line in GoalSummaryWidget, two lines max in StreakWidget lock screen fallback
- No error copy exposed in widget UI — failures silently show empty state (widget cannot present alerts)

Source: CONTEXT.md D-03 ("gentle prompt"), D-02 ("dopamine hit"), UI-02 (warm tone), codebase existing copy patterns

## Interaction Contract

**Read-only surfaces:** Both widgets are `StaticConfiguration`. No `Button`, no `Link`, no App Intents. No tappable elements inside widget views. Widget tap behavior is system-default (opens the main app).

**No loading states:** Widget views render synchronously from `TimelineEntry`. If data is unavailable (SwiftData fetch error), the empty state renders — no spinner, no progress view.

**No write operations from widget process:** `modelContext.insert` and `modelContext.delete` must never appear in widget target files. (WIDGET-04)

**Settings streak row:** Display-only. Read from `StatsViewModel` (injected `events`/`goals`) or directly from a `@Query` in SettingsView. No tap action on the streak number.

**WidgetCenter reload triggers (main app — not widget code):**
- `GoalViewModel.addGoal()` → `WidgetCenter.shared.reloadAllTimelines()`
- `GoalViewModel.updateGoal()` → `WidgetCenter.shared.reloadAllTimelines()`
- `GoalViewModel.deleteGoal()` → `WidgetCenter.shared.reloadAllTimelines()`
- `GoalViewModel.toggleCompletion()` → `WidgetCenter.shared.reloadAllTimelines()`

Dynamic Type: Widget surfaces do not support Dynamic Type scaling in the same way as app views. Use fixed SwiftUI font styles (`.caption`, `.subheadline`, `.headline`) that the system scales appropriately within widget bounds.

## Implementation Notes for Executor

1. **Target membership first:** Add `SchemaV1.swift`, `Goal.swift`, `ModelContainerFactory.swift`, `StreakEngine.swift` to the widget target before writing any widget view code.
2. **`.containerBackground(for: .widget)` is non-optional:** Apply it as the outermost modifier on every widget Entry view. Omitting it causes visual artifacts on iOS 17+.
3. **Widget process uses `cloudKitDatabase: .none`:** The widget reads from the App Group store but does not participate in CloudKit sync. Only the main app process owns sync.
4. **GoalTier.ordered drives row order:** Always `[.immediate, .shortTerm, .longTerm, .lifeGoal]` top-to-bottom.
5. **Simulator guard required in widget:** The `#if targetEnvironment(simulator)` path in `ModelContainerFactory.makeContainer()` must be preserved when widget target uses this factory.
6. **WidgetDataProvider follows GoalSorter/StreakEngine pattern:** Pure struct, no SwiftUI/SwiftData import, unit-testable without WidgetKit.
7. **Settings streak reads from same data source as StatsView:** Use a `@Query` on `CompletionEvent` in `SettingsView` and compute global streak with `StreakEngine.currentStreak(from:)`.
