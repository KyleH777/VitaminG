Security

Responsible disclosure

We take security seriously. If you discover a vulnerability in Vitamin G or our supporting infrastructure, please let us know privately so we can fix it before it affects users.

Report a vulnerability

🔒
Security email
kileharrington@gmail.com

Use the subject line [SECURITY] Vitamin G — <brief description>

Please do not open a public GitHub issue for security vulnerabilities.

What to include

  • 1
    A clear description of the vulnerability and how it could be exploited
  • 2
    Steps to reproduce — device model, iOS version, and app version
  • 3
    Potential impact on user data or privacy
  • 4
    Any proof-of-concept screenshots or code (optional but helpful)

Response timeline

48 hrsAcknowledgement
7 daysStatus update
14 daysCritical fix target
90 daysNon-critical fix target

You will be credited in the release notes unless you prefer to remain anonymous. We follow coordinated disclosure — please allow time to patch before any public write-up.

Scope

In scope

  • Vitamin G iOS app (SwiftData, CloudKit sync, auth)
  • AI proxy worker (vg-ai-proxy.kileharrington.workers.dev)
  • Community feed (CloudKit public DB)
  • Account deletion and data export flows

Out of scope

  • Apple iCloud / CloudKit infrastructure
  • Apple Sign In infrastructure
  • Anthropic Claude API
  • Issues requiring an unlocked physical device
